# Visual direction

The user requested a soft **qaymoqrang** palette with no green interface palette.

| Role             | Value     |
| ---------------- | --------- |
| Background       | `#faf7f0` |
| Surface          | `#fffdf8` |
| Text             | `#51463b` |
| Muted text       | `#7b7065` |
| Border           | `#e8dfd2` |
| Action           | `#80684f` |
| Champagne accent | `#bda17b` |

Use a plain sans serif for forms and a restrained serif for headings. Avoid
generic gradients, green accents, heavy shadows, and decorative analytics.
Keep keyboard focus, readable contrast, reduced motion, and mobile form/preview
switching.

The app currently has no installed invitation design. Keep its catalog and
preview empty states honest and visually quiet. When an exact reference is
integrated later, preserve its meaningful source animations and opening
experience, with an accessible reduced-motion alternative. The captured
reference websites and files remain outside the production app.
