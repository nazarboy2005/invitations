# Studio classical music library

The MP3 files in `apps/web/public/music/catalog/classical/` are the playback
copies, encoded at constant 192 kbps for Studio and invitations. The source and
recording details below document their provenance. Original source files are
not stored in the repository. The project does not link to a remote audio host
at playback time.

The composition may be public domain while a particular performance is still
protected. The source/license links below refer to the recording and its
performance. Creative Commons licenses permit commercial reuse and adaptations,
including synchronization, subject to their conditions. CC BY requires credit,
a license link and disclosure of changes. CC BY-SA adds a share-alike condition
for adaptations. The UI exposes the source, attribution and license for selected
tracks. The historical 1945 recording is labeled public domain by the Swiss
Foundation Public Domain collection; its performer and source are still named.
