# Template branding audit and Uzbek name recommendations

Current audit: 2026-11-08. Recommendations below are proposals, not approved renames. Only provider/generic-name cleanup has been implemented. Publication status comes from the configured database, not local fallback flags.

## Verified cleanup

- Reviewed all 130 typed catalog definitions and all 134 database template names, including hidden and database-only entries. Loaded all 133 packaged HTML entry pages and inspected 140 active HTML documents/fragments.
- Removed the remaining Maslin provider footer and translation entries, dormant Anor provider translations, and the Wedding provider favicon reference.
- Removed provider names restored by Shirin Bayram and Chavandoz localized scripts, the shared draft watermark, and calendar product identifiers in the shared runtime and two extra packaged designs. Ordinary Uzbek uses of “visol” remain invitation wording.
- Replaced the hidden Yubiley catalog cover that still pictured “Marxaba Tech” with a fresh 480×800 real-renderer opening showing the canonical “Hamkorlar jamoasi” preview. Original reference captures remain untouched; the clean capture and hashes are recorded. Both the original and versioned asset URLs were checked against the new image hash.
- Cleaned provider-bearing local fallback names, redundant “swap”/repeated “atlas” wording, and Edition display names. Admin lists display clean public slugs.
- Added neutral public URLs for Uchrashuv, Oq atirgul, Moviy ravoq and all five IDs containing Edition. Saved IDs and historical preview links still resolve to their original renderer.
- Applied only migration 0228 to the configured database. All 134 template rows were compared: names were the only changed values. The unrelated pending 0225 migration was left untouched.
- Original captures, archival source evidence and stable internal namespaces remain intact. No templates were published or deployed as part of this task.

- Focused identity/branding/routing and related package regression tests: 27 passed. TypeScript check passed. Browser routing: 41 canonical public links and historical redirects passed, with four real renderer checks and unknown-link fallback.
- Broader related tests: 50/56 passed (`related-tests.tap`). Four fail because original archive files are absent at the expected paths; two fail on unchanged blank-content/preview-fixture hash assertions. Those existing source/fixture issues are outside this cleanup.
- This audit checks packaged pages and their localized draft behavior. It does not claim to exercise every invitation interaction or arbitrary creator-authored content.
