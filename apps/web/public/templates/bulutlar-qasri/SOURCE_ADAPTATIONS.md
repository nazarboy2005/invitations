# Cloud Castle source adaptations

The archived source includes the server-rendered `preview-frame.html` and the compiled Cloud Castle page module `Chorlove/Web invitations/_next/static/chunks/14t58uni224ve.js` (module 909129; 58,812 bytes; SHA-256 `81f9356f44be09216be952fd5a90739b0796f8825c9c7c398479b3d8205cee6b`). The module contains the original component, envelope interaction, particle system, hero motion, scroll transforms, and section reveal behavior. The app package keeps the captured page subtree, utility styling, local font files, and artwork, and adapts those source behaviors without copying the Chorlove Next.js site runtime. External music, fixed Chorlove contact details, and snapshot guest names, date, venue, and wishes are excluded. The five gallery images visible in the captured page are preserved as preview-only assets, never invitation content. The original capture and compiled source remain unchanged.

`bridge.js` maps the shared invitation through `makeLegacyData` and rebinds the captured nodes for the couple, event, date, program, venue, gallery, story, contacts, gift, RSVP, guest wishes, and language. The creator preview and public route use the same renderer. RSVP and wish submissions use existing public API routes; preview submissions are disabled. Music uses the shared Emotional Piano only in catalog/selection preview and otherwise uses the creator-selected track after opening the invitation.

The catalog and initial template-selection preview use the five gallery images actually referenced by the captured Cloud Castle page. Their package copies are byte-identical to the original capture assets. They are preview-only and are replaced by creator uploads; public invitations with no uploaded photos hide the optional gallery, as the shared preview contract requires.

The captured phone and Telegram rows keep their source icons, card spacing, border, background, blur, font, and reveal profile. Their values come from invitation contacts, including the shared preview fixture in catalog/initial-selection views. The row group is hidden when an invitation has no contacts. Source owner phone and social handles are not included; no Instagram field exists in the shared invitation contract.

The source and packaged page were compared at 1280×720 and 390×844. The five source gallery image slots have matching package rectangles at both sizes after aligning the page scroll position; the captured gallery artwork, all 21 files under `images/cloud-castle/`, and all 12 captured Next media files have byte-identical package copies. Both shared CSS chunks match the captured chunks after normalizing line endings and rebasing local font URLs; the seven font files named by the source `/fonts/` CSS URLs also match their packaged media copies by SHA-256. The cover uses dynamic invitation text, so a longer title can wrap to more lines while retaining the captured font and CSS.

A further live in-app browser comparison at 1280×720 opened both the archived source and packaged preview with their source CTA. Both landed on the same full-screen cloud artwork and matching ornament, heading, and couple-name composition. The source uses its captured names while the package uses canonical fixture names, as intended. The heading uses the same loaded `DFVN New Eddy` family at 60px/75px. In the full preview, all five gallery images loaded in captured order (`gallery-2`, `gallery-1`, `gallery-3`, `gallery-6`, `gallery-4`); after aligning source and package scroller offsets, each slot's x/y/width/height matched within 0.0003px. A real catalog-preview route with `qaReducedMotion=1` passed that flag to the template frame; the frame had no CSS animation names, opening skipped the envelope transition, and all eight sampled section headings were immediately visible with opacity 1 and no transform. The captured Motion runtime sets `reducedMotion: "never"`, so reduced motion is a platform accommodation rather than behavior from the original source.

The adapter reproduces the source's 32 deterministic flower particles, two-second heart pulse, three-second button sheen, 0.8-second envelope-card exit, 0.8-second floral-edge scale/fade, 0.85-second particle burst, and 0.6-second delayed overlay fade. Ambient particle motion follows the captured component's per-property transition semantics: falling has the particle-specific delay; sway uses the half-duration keyframe sequence in alternate/reverse cycles; rotation repeats linearly with no fall delay. The captured component uses `initial={false}`, so ambient opacity stays at each particle's deterministic source opacity; opacity changes only during the opening burst. The package sets that source opacity on the particle wrapper and applies the burst fade there. It applies the source hero entrance values: logo 0.75 seconds; greeting 0.75 seconds after 0.08 seconds; couple 0.9 seconds after 0.14 seconds. Cloud/castle scroll transforms follow source ranges: castle scale 0.8–1.5 and y 0–90px; left cloud -90–240px, far-left cloud -320–190px, right cloud 145–-260px. The seven gift-box ornaments use their original float/rotate loops, durations, and delays.

The source module has multiple scroll-reveal profiles rather than one shared reveal: hero, schedule rows, gallery artwork/items, gift content, contact links, dividers, and guestbook use different thresholds, durations, easing, and stagger. `bridge.js` selects those source profiles from the captured inline start transform and corresponding template section. All source section observers retrigger when elements leave and re-enter view (`once: false`). Exact profile values are recorded in `source/provenance.json`. The archived shared Motion runtime's default `MotionConfigContext` sets `reducedMotion: "never"`; no site-level user-reduced-motion override was found in the recovered chunks, so the original component does not establish OS reduced-motion parity. The platform adapter additionally honors OS and QA reduced-motion settings, skips the opener transition, suppresses ambient/entrance motion, and avoids animated scrolling as required by the shared template contract.

The captured contact links also define `whileHover={{scale:1.03,y:-2}}` and `whileTap={{scale:.98}}` without a local transition override. The recovered Motion runtime's default spring is stiffness 500, damping 25, and rest speed 10. The adapter now applies the same spring response to separate CSS `translate` and `scale` properties, preserving the viewport reveal's independent `transform`; reduced-motion mode skips these added interactions.

The captured venue section includes a Yandex map iframe (`280px` on narrow screens, `380px` at desktop, with `340px`/`560px` maximum widths) inside the same scroll-reveal wrapper. The package now restores that iframe from the invitation's latitude/longitude, preserving the captured responsive dimensions and reveal. It does not retain the source demo venue coordinates; invitations without coordinates keep the source venue heading/address and any supplied map link without a fabricated map.

The source map section is selected by its captured `invite-map` marker, because it has no `venueName` field marker. In the paired browser check, the package created a Yandex marker from invitation coordinates 41.2995, 69.2401 without reusing the source demo location. At 1280px viewport width the iframe is 560×380px, matching the source desktop CSS. At a 390px viewport it is 327×280px before the source reveal scale, within the same 340px maximum width; the source mobile rule also specifies a 280px iframe height.

The guestbook reuses the captured bounded 500px scroll pane, width, spacing, visible source wish-generation control, and card treatment. Approved platform wishes supply their author, message, and `submittedAt` date. The source has no RSVP party-count selector, so the adapter sends a fixed party size of 1 for yes and 0 for no. Cloud Castle also has no dress-code section; the shared optional-sections adapter's generic dress-code panel is suppressed for this template.

The source gift-box trigger opens a centered `role=dialog` card over a `bg-black/75` blurred backdrop. The dialog uses the source cream panel, navy card styling, gift icon, close button, and clipboard copy action; its 250ms entrance/exit uses opacity plus scale .92→1 and y 20→0. The source `gift.webp` was copied byte-for-byte into the package. Platform card number and holder values populate the source layout; the source demo card details are not included. Escape and backdrop clicks close the dialog, alongside its close button. Reduced-motion preference removes the transition.
