# Toscana catalog artwork provenance

The reference metadata names `preview.webp`, but neither the untouched source
capture nor the initial package contains that file. The reference opener uses
`art/aisle.webp` directly as its full-viewport `.intro__poster` (`900 × 1350`,
2:3 portrait, `object-fit: cover`). The packaged `preview.webp` is an exact
byte-for-byte copy of that same source asset. It is not cropped, recomposed, or
redesigned, and it points the catalog at the opening scene rather than the
separate post-opening `art/arch.webp` hero image.
