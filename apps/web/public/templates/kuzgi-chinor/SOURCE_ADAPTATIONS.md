# Kuzgi Chinor platform adaptations

The captured invitation body, styles, and motion remain intact. The HTML head
loads the local font package, shared Marxaba runtime, and this small adapter
stylesheet.

The captured To‘yona section has bank-name and gift-note hooks that are not
fields in the approved invitation contract. The scoped CSS hides only those
empty hooks, preserving the card number and holder provided by the preview
fixture or creator content. No provider label or example gift detail is added
to saved invitations.

Catalog-only program, wishes, gift, contact, and empty Lahzalar content use the
central preview fixture. Empty gallery cards keep the captured layout and use
the shared icon fallback and carousel controls.
