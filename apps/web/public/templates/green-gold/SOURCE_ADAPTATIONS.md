# Green Gold source integration

This staging package preserves the captured `preview-frame.html` byte-for-byte and keeps the five available `images/green-gold/` artwork files separate under `assets/`. The source references a sixth file, `vertical-line.png`, that is absent from the full Chorlove archive; it remains documented as missing and is not replaced. `source-assets.provenance.json` records source, artwork, and stylesheet hashes. Both captured source CSS chunks are preserved under `source/styles/` for fidelity review; they are not loaded as global application styles.

The snapshot embeds Next.js runtime and sample invitation data. It also references six Orchid Amplop gallery photos; those unrelated sample images are intentionally not copied. The app adapter must preserve Green Gold's source design, bind all visible fields and interactions to the shared invitation contract, use shared Emotional Piano, and keep catalog sample values preview-only. Registration and publication remain gated on the completed adapter, authentic fixture preview capture, and release checks.
