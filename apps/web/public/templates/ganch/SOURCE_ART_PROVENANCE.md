# Ganch catalog artwork provenance

The catalog points to `preview-browser-capture.jpg`, captured from the production preview route `/preview?template=ganch&qaSilent=1` in the ChatGPT in-app browser. The shared canonical fixture populates the actual source renderer. The 478 by 668 JPEG SHA-256 and central fixture SHA-256 are recorded in `preview.provenance.json`. It represents the first viewport, not a full-page image.

The untouched source archive declares `preview.webp` but does not contain it. Its older packaged artwork had stale A&M and 18:00 pixels; that file is no longer the catalog preview. The captured source and its three artwork files remain byte-for-byte unchanged.
