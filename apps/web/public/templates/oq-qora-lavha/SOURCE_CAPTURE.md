# Monochrome Editorial source package

- Exact E-invitation catalog ID: `monochrome-editorial-edition`.
- Source demo: `https://e-invitation.uz/demo/monochrome-editorial-edition/`.
- Preserved original HTML, Vue module (reference only), design/shared CSS, five captured artwork files, and the local font CSS/files. `renderer.css` is an app-owned selector adaptation; source files remain unchanged.
- Source module supports cover, invitation, calendar/countdown, location, guest table, gallery, RSVP, gift, and closing sections. An app-owned renderer maps invitation names, guest greeting, message, event date/countdown, venue/map, gallery, gift, contacts, RSVP, wishes, locale, and music to app invitation data and APIs. Catalog mode uses Emotional Piano; live invitations use the creator-selected track.
