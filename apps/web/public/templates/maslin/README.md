# Maslin source package

Source: live Marxaba page `https://marxaba.uz/templates/maslin/index.html`; the existing source capture archive has no Maslin folder. The isolated package includes the complete Maslin page structure, its template and envelope CSS/JavaScript, locale dictionary, metadata, original design art (`bouquet`, both seals, cameo photo/frame, olive paper, lace), and local Cormorant Garamond / Great Vibes files. Shared runtime, codec, language, and animation dependencies are loaded from the app's existing `shared/nikoh` package; the reference site's general runtime, analytics, and sample invitation script are excluded.

The page includes invitation wording/hosts, calendar and countdown, program, venue/maps, dress code, gallery, RSVP (yes/no/maybe), wishes, To'yona card details/copy control, contacts, music, and the animated envelope opening. The source does not contain story, extra-people, receipt-upload, or RSVP party-size sections; the adapter hides unsupported story/extra-people/receipt fields without changing saved invitation data, and the source party-size markup was removed entirely to comply with the approved fixed-party-size contract behavior. The shared runtime submits party size 1 for `yes`, 0 otherwise. Empty source gallery placeholders now fall back to an available venue photo for the cameo.

The app adapter is `apps/web/src/templates/marxaba/maslin.tsx`; it delegates typed data and public RSVP/wish APIs to `MarxabaInvitation`. The source `venue.brand` slot is bound from the contract venue name. Static sample names/date/address were removed from dynamic slot fallbacks. Local runtime paths replace reference-site runtime links, and font requests are served locally. `envelope.js` uses the shared runtime's `lang` field for its opening labels and includes a narrow Uzbek Cyrillic conversion because the shared runtime has no exported `MarxabaCyrl` helper. `envelope.css` explicitly displays the source lace layers in the shared platform frame.

The catalog-facing name is **Zaytun maktubi** (Olive Letter). Uzbek Latin is the default for the complete page, metadata, controls, and accessibility labels; the original Russian-inspired visual direction is retained through the artwork, palette, typography, composition, and animation. `i18n.js` contains Russian and English versions for the fixed interface copy. Names, dates, addresses, program entries, and other creator-authored content stay dynamic and come from the typed invitation contract. No source demo names are used as content defaults.

The source's `preview.webp` contains example names and a date, so it is deliberately absent from the app package. Generate a renderer-based portrait cover from the centralized preview fixture before catalog registration. Catalog/database registration, public-route verification, and publication remain pending coordinator review. The package has not been committed or made selectable.
