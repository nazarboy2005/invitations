# Olive Manor

Complete original source composition, scoped CSS, local fonts, envelope/wax,
opening video, gallery, calendar, venue, gift, RSVP, contacts and closing artwork.
`source/reference` preserves the older archive; `source/current` contains the
complete current reference and provenance. Its additional intro stylesheet is
`inline.css`; it must accompany `template.css`.

`motion.js` retains the source opening sequence. The shared E-invitation adapter
binds creator data and Fotiha services without the provider runtime. Preview
photos come only from the canonical fixture. See
`docs/templates/e-invitation-repair/README.md` for mappings and verification.
