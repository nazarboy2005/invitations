# Safir template package

Source: `Invitations - this folder will be removed from production/Invitate/capture-manifest.json` resolves to `Web invitations/invitate.uz/safir.html`. The captured Safir stylesheet, JavaScript, fonts, eleven Safir image assets, and two shared scene images are in the same Invitate source tree. Original captures remain untouched.

The page structure and visual CSS are adapted from Safir. The captured `safir.html`, stylesheet, and original `safir.js` are preserved unchanged under `source/`; `index.html` and `bridge.js` are the adapted production copy. The eleven template images remain under `assets/images/safir`; the original shared 0310 hero and closing scenes are under `assets/images/0310`. Cormorant Garamond, Great Vibes, and Montserrat files are served locally. `bridge.js` adapts source scroll reveals and control behavior to platform data and APIs. The capture's analytics, reference-site metadata, fixed invitation data, external audio path, and `safir.php` RSVP post are excluded. RSVP and moderated wishes use the app's public APIs. The source animation classes are retained and observer-controlled, and the hero-label centering accounts for the source's animated vertical transform.

The renderer binds invitation names, greeting/message, date, venue/address/map, repeatable program rows, dress code and palette, phone contact, optional creator music, RSVP, and wishes. The captured couple portrait remains as a template image when no creator gallery photo is present; the first creator gallery upload replaces it. The design has no separate calendar action, story/gallery section, To‘yona card, gift section, or wish list. Safir supports wedding events and Uzbek Latin, Uzbek Cyrillic, English, and Russian. The fixed language selector follows enabled invitation locales. Motion follows `prefers-reduced-motion`; music starts only after a guest activates its control.

`catalog-cover-opening.png` is a 430×931 capture of the packaged source's closed-envelope opening. It uses no invitation data, waits for local fonts, and hides only the fixed music and language controls and scrollbar during capture. `preview.provenance.json` records its route, source, dimensions, and SHA-256.
