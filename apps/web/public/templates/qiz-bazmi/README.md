# Qiz Bazmi source package

This package preserves the captured Qiz Bazmi invitation markup, stylesheet, animation script, localization, and art. The `index.html` dependency references are adapted to the shared self-hosted Marxaba runtime and platform bridge. Its captured `sample-overrides.js` is intentionally excluded; the invitation is populated from the typed platform payload. Manrope and Playfair Display files are served locally.

The captured metadata declares `qiz-uzatish`, `fotiha`, and `tugilgan-kun`; the typed catalog and database map `tugilgan-kun` to the shared `birthday` event type. Its explicit preview event type is `qiz-uzatish`, with localized single-celebrant and program content from the central preview fixture. `extras.celebrant` is rendered from the bride/person field by the original script fallback. The source contains `venue.photo`, `toyona.bank`, and `toyona.note`; these do not exist in the approved shared invitation contract, so the platform adapter supplies no values for them. The editor's venue-photo and bank-name fields are intentionally absent under the current product decisions. The gift note has no shared persisted field and remains an unresolved contract gap.

`meta.js` points to `preview.webp`, which is absent from the reference capture. The packaged `preview.webp` is a screenshot of the actual source opening rendered by headless Chrome from `http://127.0.0.1:3002/templates/qiz-bazmi/index.html?lang=uz` at 450×800 (9:16), after local fonts and the canonical `preview-sample.json` greeting loaded. The PNG screenshot was converted to WebP in Chromium Canvas at 94% quality. No artwork was generated or substituted.
