## Paired reveal timing follow-up (2026-10-26)

A frame-sampled 480×720 browser comparison of section 1 exposed a small source-motion mismatch that the initial settled-state comparison could not show. The archived module defines all four corner ornaments with the same `whileInView` trigger and `transition:{duration:.8,ease:"easeOut"}` and has no per-corner delay. The package had added an extra 20ms per-corner delay. Under matched instant section positioning, source corner opacity progresses in lockstep (all four reach 0.257 at roughly 150ms); package corners were staggered (0.234, 0.203, 0.171, 0.139). I removed the package-only stagger, so all four now use the source 800ms ease-out entrance concurrently.

The same live gallery comparison found that generated photo cards remained at `opacity:0`: the adapter queried the literal substring `opacity:0`, while the browser normalized the inline style to `opacity: 0`. It also based each card's delay on its position among all section elements rather than its gallery index. The adapter now finds zero-opacity elements by computed style and assigns each photo its source index. It observes each gallery item at the source 0.35 visibility threshold and replays its source 800ms ease-out entrance once when that card enters view, with delays 0/100/200ms repeating across the six items. At the gallery's initial position, both pages animated cards 1–3 and left 4–6 untouched; after scrolling down 440px, both animated cards 4–6. Each card used the same 800ms ease-out and 0/100/200ms delay pattern. The independently sampled opacity values differed by at most 0.024 at 350ms, consistent with the two browser observers starting a few frames apart. This matches the source component's per-card `whileInView` behavior; section-level visibility alone no longer starts offscreen card animations. The package has no browser page errors; the archived browser still logs React hydration error #418, but its gallery and section animations run after recovery. The focused source test pins the no-stagger corners, gallery indexing, and per-card observer behavior.
