# Xatna Edition

Complete original doors, animated greeting, child/horse scene, calendar,
countdown, quote, courtyard, contacts, gift and embroidered closing arch. Local
current source/asset/font hashes are under `source/current`; the older capture
remains under `source/reference`. The original gallery component is retained for
creator uploads without introducing unrelated preview photos.

The source's 1,000 ms doors and 520/92 ms calendar sequence are retained. Creator
data and Fotiha services use the separate shared E-invitation adapter. This design
supports `sunnat-toyi`. See `docs/templates/e-invitation-repair/README.md` for
mappings and verification.
