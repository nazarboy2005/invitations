# Xatna Edition source package

- Exact E-invitation catalog ID: `xatna-edition` (`Xatna Edition`), separate from Invitate and Chorlove.
- Original source capture preserved in `source/reference/`: HTML, Vue module (reference only), design/shared styles, six artworks, local font files, and source gap report. Source-site application chunks are not executed.
- App renderer adapts the gate opening, hero, child, date/countdown, venue/map, program, gallery, gift, RSVP/wishes, contacts, and music to app invitation fields/APIs. Catalog mode uses Emotional Piano; live invitations use creator-selected music.
- The Vue module also references `farewell-embroidered-arch.webp` and `quote-divider.webp`, absent from the supplied source capture and unavailable from their exact asset URLs. Do not treat replacement borders/decorations as original.
- Registration is unpublished; do not publish until source parity and authenticated lifecycle checks pass.
