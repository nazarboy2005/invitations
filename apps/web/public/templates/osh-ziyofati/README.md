# Palov source package

Source: `Invitate/capture-manifest.json` resolves Palov to `Web invitations/invitate.uz/palov.html`. The selected page contains the complete captured visual HTML, inline stylesheet, SVG artwork, and inline interaction script. The reference capture remains untouched.

`index.html` preserves the captured page structure, inline art, styles, and motion. It removes analytics, remote font loading, hard-coded sample host/date/venue/contact values, and the captured local-only RSVP simulation. Fonts are served locally, and `assets/images/palov.png` remains as the template-owned Palov artwork. Other files in the site's aggregate capture manifest are not dependencies of this selected page and are excluded. The adapted `assets/js/palov-adapter.js` binds the shared Invitate payload to captured fields, localizes built-in controls, updates the event countdown, respects the captured reduced-motion CSS, connects RSVP to the public API, and starts optional music only after a guest click.

Field mapping: event label, hosts, date/time/timezone-derived countdown, greeting and personalized guest greeting, invitation message, venue/address/map link, the source's single replaceable image slot (while retaining the Palov illustration as template art), phone/Telegram contacts, optional music, and RSVP. The selected source has no authored program list, story, dress code, To‘yona, wishes, or multi-photo gallery controls. Catalog and initial-selection sample content comes only through the shared ephemeral preview fixture.

The design targets morning osh and is compatible with event type `osh` only. Its category assignment is independently `osh`. `preview.png` is a 480×860 portrait capture of this adapted page's actual opening, rendered with the shared `createTemplatePreviewSample("invitate-palov")` fixture. Fixture content is used only for the catalog artwork and is not part of creator or public invitation data. The completed template is published at 150,000 UZS through additive migration `0132_publish_invitate_palov.sql`.
