# Nilufar source package

The captured template source remains untouched. The app package preserves the
captured body, styles, metadata, fixed-copy dictionary, five pond artwork files,
and 3D opening implementation. `index.html` binds the event label to the typed
`eventType` slot and loads local fonts plus the isolated shared Marxaba runtime.
`template.js` changes only the Three.js bundle path to the local shared vendor.

`preview.webp` is byte-identical to the captured 1080×1920
`art/poster-pond.webp`, which is the first static opening background before the
interactive pond canvas animates. `preview.provenance.json` records its source
and checksum. The shared typed adapter maps the central preview fixture for all
four locales and leaves blank creator drafts empty; it supplies the same
renderer to editor and public invitation routes.

The captured `venue.photo`, `toyona.bank`, and `toyona.note` hooks have no
approved invitation fields. The adapter supplies no values for these hooks;
the package-only CSS hides empty bank and note rows. Card number and cardholder
remain bound to the approved gift fields. Source event metadata maps to the
`wedding` and `fotiha` event types, independent from the wedding catalog
category. Catalog preview chooses Fotiha so the opening label matches this
design; the remaining preview values continue to come from the shared
preview-only fixture.

Nilufar remains unpublished until desktop/mobile browser interaction,
reduced-motion runtime, API-backed save/reopen, and public service checks pass.
