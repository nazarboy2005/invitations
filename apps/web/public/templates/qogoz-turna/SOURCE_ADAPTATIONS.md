HTML head loads local fonts, the shared Marxaba runtime, and this scoped adapter
stylesheet.

not present in the approved shared invitation contract. The adapter hides only

paper crane, invitation tag, names, date, and open button. The previous image
showed the Registan scene from the page after the invitation opens. The capture
uses the source HTML and stylesheet with the source arrival animation frozen at
its authored end state; only the canonical preview fixture values are supplied.
