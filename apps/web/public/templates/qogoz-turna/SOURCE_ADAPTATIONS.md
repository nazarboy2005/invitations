# Qog‘oz Turna platform adaptations

The captured invitation body, styles, and paper-fold motion remain intact. The
HTML head loads local fonts, the shared Marxaba runtime, and this scoped adapter
stylesheet.

The captured To‘yona section includes bank-name and gift-note hooks that are
not present in the approved shared invitation contract. The adapter hides only
those empty rows; the sample or creator card number and cardholder remain
visible. It does not add a provider label or sample details to saved invitations.

The catalog cover is the exact original source `preview.webp` served from the
canonical Marxaba template URL and declared by the captured `meta.js`. It
depicts the source's catalog artwork. The runtime opening remains implemented
from the captured HTML/CSS/JavaScript and may show a different state. See
`preview.provenance.json` for source URL, metadata, and asset checksums.

Catalog-only program, wishes, gift, contact, and empty Lahzalar content use the
central preview fixture. The source gallery layout remains intact and the
shared runtime supplies its icon-only empty state and wraparound controls.
