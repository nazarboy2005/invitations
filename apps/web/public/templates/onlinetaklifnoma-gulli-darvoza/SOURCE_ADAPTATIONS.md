# Gulli darvoza source package

Source page: `https://onlinetaklifnoma.app/templates/gulli-darvoza/full` (capture ID `gulli-darvoza`). The untouched snapshot is under `Invitations - this folder will be removed from production/OnlineTaklifnoma/Web invitations/onlinetaklifnoma.app/templates/gulli-darvoza/full/index.html`.

The opening artwork, source-specific couple image, gate thumbnail, intro video, and font subsets were recovered directly from their original public URLs. Their origin URLs, byte lengths, and SHA-256 digests are recorded in `source/assets-provenance.json`. The source's initial DOM snapshot and the interactive live page were inspected in the ChatGPT in-app browser. The source site itself uses the shared Next.js runtime and remote data; neither its site runtime, analytics beacon, external form endpoints, nor demo invitation data are packaged. The app version keeps the source's gate/video opening, names/date/countdown cover, quiet ivory and champagne palette, Cormorant Garamond / Great Vibes / Forum typography, line ornaments, reveal motion, invitation copy, date, venue, RSVP, wishes, and close. Reduced-motion mode reveals content immediately. The optional program and photo gallery sections are bound to creator-authored fields and remain hidden when empty.

The app's typed adapter is in `apps/web/src/templates/onlinetaklifnoma/gulli-darvoza/renderer.tsx`. It sends only the active invitation's legacy-compatible contract data, personalized guest greeting, locale, selected music (Emotional Piano for catalog preview), and API identifiers to the isolated same-origin `index.html`/`bridge.js` source renderer. RSVP and wishes use `/api/public/invitations/{id}/rsvp` and `/wishes`; preview submissions are explicitly blocked. Approved wishes are loaded from the existing public endpoint. The source's optional free-text RSVP message is not included because the app RSVP contract/API has no message field; the misleading source field is omitted. Calendar export is likewise omitted because this app has no invitation calendar endpoint. The source has no gift card, so the optional gold-framed To‘yona plaque is template-specific and only renders with enabled, non-empty real cardholder and card number values; preview fixtures remain ephemeral. Receipt upload is not represented because the current public template/API does not expose that flow.

The original external capture is unchanged. `source/captured-styles/` contains the exact stylesheet responses examined for source font and motion rules; these are inspection evidence only and are not loaded by the production page.
