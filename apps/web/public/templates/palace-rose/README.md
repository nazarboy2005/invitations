# Palace Rose source package (release gated)

Source folder: `Invitations - this folder will be removed from production/Chorlove/Web invitations/templates/palace-rose`.

The manifest's exact page source is the rendered `preview-frame.html`. The application package uses its extracted `.palace-rose-page` DOM in `source/design.html`, removing the Chorlove page shell, runtime and analytics references, baked sample invitation values, remote sample music, unrelated gallery/gift images, and the fixed demo map URL. The source capture folder remains untouched. All 17 Palace Rose manifest artwork files in the recovered archive's `images/palace-rose/` match the corresponding packaged files byte-for-byte.

All four CSS files linked by the capture are packaged under `source/css/` and loaded from this template. Their capture checksums and package checksums are recorded in `source/provenance.json`; URL references are localized to `source/media/`. The two image-library stylesheets are unchanged. In the shared Next font stylesheet, unrelated application-wide font faces were omitted where the full archive has no font file; the template's captured Qellia, Cormorant Garamond, The Nautigal, Great Vibes, Fraunces, Jost, and Marcellus files are present locally. The general Tailwind stylesheet still contains Leaflet's three generic sprite URLs; those sprites are absent from the full archive and are not used by this template's iframe-based venue map.

A full archive audit also found the Palace Rose React implementation and its motion code inside shared compiled chunk `Web invitations/_next/static/chunks/0dg.9_70mpb0j.js` (module 99664). The isolated package does not load that Chorlove application bundle: it carries the captured template DOM, package-local captured CSS, and a narrow `bridge.js` contract/service adapter. The bridge preserves the source opening timing (0.6 s fade after 0.45 s, 0.8 s envelope lift, 0.85 s petal exit), the 12 source-positioned petals (per-petal 19.7–26 s fall and 1.2× spin cycles), the seal pulse, shine, flower sway, scroll parallax ranges, and section-specific reveal thresholds/staggers. Reduced motion removes those effects and leaves every section visible. The isolated page does not ship Chorlove runtime, analytics, or compiled sample invitation defaults. All six renderer font variants are present in the recovered archive's `_next/static/media/` and match the packaged files byte-for-byte. The component references eight gift-box decoration files outside its 17-file manifest asset set. Four expected gift-art hashes were found elsewhere in the archive's image tree (in other template image folders); the other four expected hashes were absent from a recursive image-file hash search. One absent file, `glass_garden_pink.webp`, has a same-named `glass-pink` artwork with different bytes, which is not used as a substitute. All eight packaged gift artworks came from the exact `/images/palace-rose/<filename>` URLs referenced by the recovered renderer; each prior exact-URL retrieval returned `200 image/webp`, with response size and SHA-256 recorded in `source/provenance.json`. The record distinguishes those URL-captured originals from local archive copies and lists each exact URL and expected hash. The captured To‘yona interaction now retains its gift art and opens the source-style modal, showing the card details and copy action or the creator's note. Reduced motion disables the modal transition. The source footer attribution link is retained as template UI; the Chorlove application runtime and analytics remain excluded.

The adapter maps names, personalized greeting, event label, hosts/message, event date and time, locale-aware date card/calendar/countdown, repeatable program, venue/address/map, creator gallery, guest wishes, RSVP, To‘yona card details, contacts, music, locale controls, and reduced motion. RSVP records a single attendee for an affirmative response and does not ask for guest count. Generic story, dress-code and extra-people sections are disabled for this source. The optional private gift receipt control mounts only inside the native To‘yona modal content while it is open. Preview fixture content is supplied only by the shared preview path and public creator media is used only when present. The packaged 450×800 opening portrait is captured from the real isolated renderer using the approved preview values; capture provenance is recorded in `source/provenance.json`.

Catalog/database registration is private (`published=false`) and wedding-only. Keep it unpublished until all interactions, four locales, reduced motion, source-motion comparison, creator/public preview parity, and focused release checks pass.

Matched browser review on 2026-10-25 compared the untouched captured `preview-frame.html` served on port 3003 with `/preview?template=palace-rose&qaSilent=1` on port 3001 at 1280×720. The opening, parallax bridge, detail section, gift modal, and footer were inspected. This exposed a date binding error: source paragraphs contain the ampersand at index 2, time label at 3, date value at 4, message at 5, and host label/value at 6/7. The adapter now preserves that structure and formats the date as `WEEKDAY • day month year • time`. The shared preview fixture has six empty gallery slots; source gallery photos are invitation sample media. Palace Rose now maps the six exact archived gallery images (listed in `source/provenance.json`) and its source venue photo only into catalog and initial template-selection previews. These values stay ephemeral in the canonical preview fixture; creator drafts and public invitations with no creator uploads hide the gallery and venue-photo slot. The source footer attribution is retained.

Normal-motion parity follow-up (2026-10-26) used the archived capture with the original compiled module on port 3004 and the package renderer at 1280×720. The source and package invitation viewports now both use a full-width, 720px-high internal scroll root with white outer gutters; their differing full-document heights reflect different invitation fixture content. Package reveal selection now avoids treating `opacity:0.7` decorations as hidden content, and the detail, calendar, venue, program-row, wishes, and gift reveals follow the recovered module's per-node durations, delays, and viewport thresholds. The opening still uses 12 petals. To‘yona keeps the source backdrop and centered panel/card layout; hiding the empty receipt host removes an unintended flex gap, while backdrop/close/Escape behavior and the copy action remain available. This visual comparison uses different source-demo and shared-preview names, so text and resulting content height are not treated as layout mismatches.

To‘yona interaction follow-up (2026-10-26) exercised both archived source and package in the browser. In both, clicking the close button or backdrop dismisses the modal, clicking inside the panel leaves it open, and copying shows the source/package success label. The archived source does not close on Escape; the package supports Escape and ARIA dialog semantics as accessibility additions. The package receipt host is moved inside the modal while open and restored hidden under `body` on close. A temporary QA-only receipt form and local dummy image (disabled submit; never uploaded or saved) confirmed source/package modal-content geometry at 1280×678 and 390×678, including the selected filename control; neither renders an image thumbnail. At compact 390×500, both panels stay within the viewport and their inner content scrolls so the close button remains visible. The shared preview has no receipt content, so an enabled creator receipt in an editor draft remains unverified.

Reduced-motion source/runtime parity was checked against the preserved CSS and isolated adapter. The captured source stylesheet `source/css/00sc_9lpb3zcn.css` disables animations on `.hero-reveal`, `.hero-star`, `.feature-orb`, and `.divider-shine` under `@media (prefers-reduced-motion:reduce)`. The adapter uses the same `prefers-reduced-motion: reduce` media query and suppresses its matching template effects: it creates no petals, skips the opening fade/lift/exit classes, immediately reveals hidden content with opacity 1 and no transform, stops scroll-parallax updates, scrolls instantly, and sets the gift modal transition duration to 0ms. The browser controls do not expose a media-preference override, so that native source media query was not toggled live; the package `qaReducedMotion=1` preview was verified with no petals and an immediately opened invitation. Remaining browser-dependent gates are a database-backed public invitation (`DATABASE_URL` is not configured locally) and an editor draft with an optional receipt host (not enabled in the shared fixture); keep Palace Rose unpublished.
