# Monochrome Editorial

Complete source opening card, photography, paper transitions, invitation,
calendar, venue, gallery, RSVP, gift and final scene. `source/current` preserves
the full current DOM/module, scoped CSS, local fonts and authentic assets with
provenance; `source/reference` preserves the original archive.

The source's 920 ms opening and 650 ms fade are retained. The shared adapter binds
typed creator data and Fotiha services in place. The current source does not use
the obsolete missing paper edge described by the older archive. See
`docs/templates/e-invitation-repair/README.md` for mappings and verification.
