# Green Garden source integration

The archive supplies only `preview-frame.html`, an SSR snapshot that includes Next.js runtime data and sample invitation content. Its original bytes are preserved in `source/preview-frame.html`. This staging package contains design ornaments and the source page's Cormorant Garamond, Qellia, and The Nautigal font files captured through the approved in-app browser. `source-assets.provenance.json` records hashes and origin.

The snapshot depends on the existing shared Chorlove Next.js utility and font styles. Its template includes a floral opening, a long invitation page, a six-photo sample gallery, calendar/map controls, RSVP, guest wishes, gifts, contacts, and a dress-code section. The local adapter must replace the snapshot names, date, venue, contact details, stories, and program with the shared invitation contract; the six sample gallery photos and source music must not ship in the runnable template.

The isolated page adapter is under active integration. It binds the couple, greeting, event, date/calendar, venue/map, schedule, authored gallery, contacts, RSVP, wishes, gift card details, music, language selection, countdown, and reduced-motion reveal behavior to the shared Chorlove iframe payload and existing invitation APIs. The captured sample gallery, contact handles, names, venue, date, and wish text are removed. The capture references absent `leaf1-bloom.webp`, `welcome.webp`, and `cake.webp` files; those missing decorative images are omitted instead of being replaced with unrelated artwork. The original capture remains byte-for-byte unchanged.
