# Green Garden source integration

The canonical capture is Chorlove's server-rendered `preview-frame.html` snapshot. Its exact archived bytes are preserved at `source/preview-frame.html`; the source hash and byte length in `source-assets.provenance.json` match the Chorlove archive. The snapshot contains Next.js runtime data and sample invitation content, but the runnable page uses the isolated adapted structure, local shared styles, and Green Garden assets rather than the captured site runtime.

Green Garden's own floral background, opening decoration, source ornaments, and Cormorant Garamond, Qellia, and The Nautigal font files remain packaged with the renderer. All 15 image files present in the archived Green Garden source image folder match their packaged copies byte-for-byte; the SHA-256 comparison is recorded in `source-assets.provenance.json` and checked by the focused test. The source program uses three decorative schedule icons: `welcome.webp`, `cake.webp`, and `dish.webp`; the first two were missing in the archive but their exact Chorlove URLs returned 200, so they were restored with hashes recorded in the manifest. The snapshot's six gallery image URLs point to Orchid Amplop sample photos, so those cross-template sample photos stay excluded. The original hero markup includes two references to `images/green-garden/leaf1-bloom.webp`, but the Chorlove archive contains no Green Garden file at that path (the similarly named Glass Pink file is a different asset). Both missing leaf references are preserved as captured because the source asset returns 404; the similar Glass Pink image was not substituted.

The Chorlove adapter maps the shared invitation contract to the couple, greeting, event, date/calendar, venue/map, schedule, creator gallery, contacts, RSVP, wishes, To'yona card details, music, locale controls, countdown, and reduced-motion reveal behavior. Preview gallery placeholders come from the shared sample fixture and remain ephemeral. A creator's uploaded gallery images replace those empty preview slots; in public invitations, the optional gallery section stays hidden until an authored image is present. Sample invitation values and cross-template gallery photos are never added to drafts or published invitations.

The catalog artwork is the full 432×768 portrait opening captured from Chorlove's archived source snapshot, including the source names/date, original flower arrangement, opening button, and music toggle. `catalog-cover-opening.png` and `preview.provenance.json` record its capture details and SHA-256; the former packaged-renderer preview remains available as QA evidence.

The adapted hero uses the archived source section markup and retains its dynamic couple fields. The compiled module supplies the entrance and scroll motion: 1-second leaf reveals at 0.2/0.35 seconds, a 0.9-second glass-card entrance at 0.25 seconds, groom/ampersand/bride entrances at 0.7 seconds with delays of 0.4/0.55/0.7 seconds, flower entrance, twelve original petal timings, and the 0–600px parallax ranges (-180/-140/-40px). Hero animations begin when the visitor opens the invitation, matching the source component state change. Opening close uses the source card lift/fade, delayed overlay fade, and 0.85-second petal exit. The three schedule icons, staggered schedule rows, gallery-independent wish cards, contact links, and seven To’yona ornaments use the source entrance or floating/rotation timings. Reduced motion cancels active Web Animations and shows the final hero state.

The two hero leaves still reference `/images/green-garden/leaf1-bloom.webp`, as in the archived HTML and route module. The complete local archive search found only a same-named Glass Pink image, which is a different pink flower; the current Chorlove URL returns HTTP 404. No replacement was added. This source asset is unavailable for exact local restoration, and the original reference itself currently renders those two images broken.

Green Garden remains published through migration `0095_publish_green_garden.sql`; this repair does not change publication, price, or event compatibility. The To'yona gift toggle and card number/cardholder details continue to bind from invitation data. The original source archive remains untouched.
