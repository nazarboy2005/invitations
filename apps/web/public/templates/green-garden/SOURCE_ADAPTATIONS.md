# Green Garden source integration

The canonical capture is Chorlove's server-rendered `preview-frame.html` snapshot. Its exact archived bytes are preserved at `source/preview-frame.html`; the source hash and byte length in `source-assets.provenance.json` match the Chorlove archive. The snapshot contains Next.js runtime data and sample invitation content, but the runnable page uses the isolated adapted structure, local shared styles, and Green Garden assets rather than the captured site runtime.

Green Garden's own floral background, opening decoration, source ornaments, and Cormorant Garamond, Qellia, and The Nautigal font files remain packaged with the renderer. The snapshot's six gallery image URLs point to Orchid Amplop sample photos, so those cross-template sample photos stay excluded. Its references to absent `leaf1-bloom.webp`, `welcome.webp`, and `cake.webp` remain documented and are not replaced.

The Chorlove adapter maps the shared invitation contract to the couple, greeting, event, date/calendar, venue/map, schedule, creator gallery, contacts, RSVP, wishes, To'yona card details, music, locale controls, countdown, and reduced-motion reveal behavior. Preview gallery placeholders come from the shared sample fixture and remain ephemeral. A creator's uploaded gallery images replace those empty preview slots; in public invitations, the optional gallery section stays hidden until an authored image is present. Sample invitation values and cross-template gallery photos are never added to drafts or published invitations.

The catalog artwork is a clean 390×720 capture of the packaged renderer's full floral opening using the current canonical shared fixture. The full iframe viewport is preserved without crop or resize; browser/app UI, the injected language selector, scrollbar, and development portal are excluded. `preview.provenance.json` records the fixture, source, and artifact SHA-256 values and capture dimensions.

Green Garden remains published through migration `0095_publish_green_garden.sql`; this repair does not change publication, price, or event compatibility. The To'yona gift toggle and card number/cardholder details continue to bind from invitation data. The original source archive remains untouched.
