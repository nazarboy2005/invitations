# Oathbound source package

Authoritative capture:
`Wedivo/Web invitations/templates/uVaSW0h4UZuI8iAo9SdV/index.html`
under the nested `Invitations - this folder will be removed from production`
archive. The manifest identifies the design as embedded-source. Its adjacent
`source.html` is the same captured document. Captures are not edited or served
by the application. `source/provenance.json` records the original HTML, embedded
script/style and all dependency hashes.

## Exact source retained

- `source/template.css`: all captured template styling; only the font import
  and four external decorative texture URLs are replaced by local links.
- `source/template.js`: captured standalone RPG implementation. The complete
  procedural engine prefix through the DOM-content helper boundary is identical
  after line-ending normalization. Packed meshes, shaders, rigging, world,
  particles, pathfinding and game controls are not redrawn or replaced.
- `assets/art`: four byte-identical source leather/parchment/cloth/sky textures.
- `assets/fonts.css` / `assets/fonts`: ten captured exact TTF faces: Cinzel
  Decorative 700/900, Cinzel 500/600/700/800, EB Garamond 400/500/600 normal
  and 400 italic. No remote font requests are needed.
- `assets/preview`: six byte-identical source gallery photos, supplied only by
  the typed adapter in canonical sample preview mode. They never enter drafts
  or public payload defaults.

## Essential adaptations

`index.html` retains the source HTML/SVG structure. It excludes the provider
parameter manifest, preview shim, embedded demo rundown, sample wishes,
invitation-specific names/dates/media/handles/venues, provider map credentials,
YouTube/music examples and remote resource URLs. It loads local source CSS/fonts
and a separate platform adapter. The RSVP party-size controls and unsupported
source check-in button are removed; gift inputs remain in their native design
but disabled. Demo person-specific slots are blank before first paint.

`platform-adapter.js` supplies escaped text through DOM APIs and starts the
original source script only after a valid payload is available. Updates reload
the isolated frame from its latest payload, avoiding stale game/DOM state. The
postMessage receiver checks both origin and owning parent. Source game progress
is local to each invitation and preview/public mode, without storing submitted
form content or guest tokens. Locale is supplied by the shared renderer.

Source script changes are narrow contract hooks: dynamic gallery/story/dress
counts; source data-dependent event/phase/calendar/venue builders; correct
instant/local date/time handling; optional audio URL acceptance of local paths;
preview silence; per-invitation progress key; no headcount button handlers;
source boot callback; and reduced-motion/no-background-drawing guards. Its
original source modes, world motion and interaction handlers remain in use.
CSS platform additions provide reduced motion, disabled-state clarity,
overflow-safe names, and visibility while awaiting data.

The later Uzbek-default user instruction is implemented through
`platform-i18n.js`: the displayed design name is “Ahd yo‘li”, with natural
Uzbek translations for every source UI category including game dialogue,
tooltips, aria labels and CSS-generated labels. A source `say` hook translates
dialogue before typewriter playback. A scoped text observer translates source
game status updates before paint; authored content nodes and inserted personal
names are protected. The original source language remains in the preserved
engine text, never as the Uzbek default display. Captures remain unchanged.

Unsupported authoring fields are listed in the typed renderer README. The
source amount form has no approved transfer-confirmation API, so an explicit
localized notice accompanies its disabled controls. No transfer/payment success
or gift delivery is simulated. RSVP/wishes success is shown only after a
successful platform API response; pending wishes stay out of the public list.

The 450×800 `preview.png` is a screenshot of this actual source opening using
the canonical preview sample, Uzbek title/copy and the original WebGL dice.
For this static capture only, QA skips initialization of the invisible world
behind the closed cover; the original die, typography, textures and CSS motion
still run. `preview.provenance.json` records that override and the source,
fixture and cover hashes. Desktop and mobile source/package opening captures
use the same condition. No production rendering override is included.
Publication remains coordinator-managed and blocked on the outstanding
authoring/service, full-world, Russian narrative and real integration gates.
