# Velvet Royale app adapter

Source identity is E-invitation catalog ID `royal-burgundy-edition`; the local source capture and recovered source package remain unchanged under `source/reference/`.

`index.html` and `renderer.js` are an isolated app renderer built from the captured Royale Vue module's observed section tree and matching scoped styles/assets. The original Vue module imports the E-invitation site registry and shared Nuxt/Vue runtime, so none of those site-wide modules, tracking, webhooks, sample names, source demo venue/card/contacts, or its demo audio are loaded here. `renderer.css` is a production copy of the captured `VelvetRoyale.Bur_z5Os.css` with Vue-generated `[data-v-*]` selector constraints removed so matching section classes work in the standalone iframe; `adapter.css` supplies locale, editor data, and reduced-motion bindings absent from the source stylesheet. `source/reference/VelvetRoyale.Bur_z5Os.css` remains the untouched captured stylesheet.

The React adapter in `apps/web/src/templates/velvet-royale/renderer.tsx` maps the shared contract to the same-origin iframe and routes locale changes, catalog preview music, authored music, guest token, RSVP, and wishes data. The catalog fixture alone fills its six-photo source gallery with recovered local source-gallery artwork; real invitations use only creator-uploaded gallery images and hide the optional gallery when empty. The opening action is one-shot, while `qaReducedMotion=1` provides an app-preview test switch alongside the operating-system preference so reduced-motion behavior can be checked in the in-app browser. The preview-only `qaMobile=1` harness constrains the outer renderer to 390px so the iframe uses a narrow viewport during in-app-browser review; neither QA switch affects public invitations.

Known source-to-contract gap: the reference page can display a guest-specific table assignment, but `Invitation` and `resolveGuest` currently provide no guest table field. The app adapter does not show a hard-coded/demo table number. Source sample venue, card number, personal contact, invitation date, and demo music are excluded from real invitations.
