# Islamic Edition

Complete original green/gold composition, door video, animated greeting, original
star engine, calendar, ambient video, gallery, gift, venue, family and closing.
Original scopes, artwork and local fonts are under `source/current`, with hashes
in `provenance.json`; the older `source/reference` archive remains unchanged.

`motion.js` and `stars.js` retain source motion. The separate shared adapter binds
creator data, Fotiha APIs and Yandex Maps. No provider runtime/API/music is loaded.
See `docs/templates/e-invitation-repair/README.md` for mappings and verification.
