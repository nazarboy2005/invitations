# Jasmine White source adaptations

The visual reference is `source/preview-frame.html`, captured byte-for-byte from the archived Chorlove Jasmine White page. The original template module and animation definitions are in `Invitations - this folder will be removed from production/Chorlove/Web invitations/_next/static/chunks/0ziyt946s2g41.js` (SHA-256 `C126D27D5F78DA03D1EF1C4FC5320247D00DC18F697CD3EF0CE2E250AE1335C4`). Both captured stylesheets now load byte-for-byte from the isolated package. The capture and copied asset hashes are recorded in `source-assets.provenance.json`.

`bridge.js` keeps the captured HTML, CSS, images, and font files in the package, and binds invitation data and platform actions to those elements. The source motion chunk is hash-pinned and referenced from the local archive. Fidelity regression checks assert the original opening-petal scale sequence `[1,2,0]`; the adapter now uses the exact 2× midpoint. It replays the source envelope fade (600 ms after a 450 ms delay), envelope lift (800 ms), flower exit (800 ms), petal burst (850 ms), and 1,050 ms overlay lifetime. On opening, the hero enters over 900 ms after a 200 ms delay. The opener also has 12 source-configured falling petals, a heart pulse (2 seconds), and button sheen (3 seconds). Section reveal profiles preserve the source transforms, transition timings, delays, and viewport thresholds. The seven gift flowers use the source lift, rotation, duration, and delay values. The gift artwork opens a source-styled full-screen modal with the captured 250 ms backdrop and card entrance/exit; card details and copy action are supplied by the platform adapter.

The captured CSS references 30 runtime font files; all are packaged and mapped to local URLs. The captured page also declares four named typefaces from the provider `/fonts/` directory; those exact archive files (Qellia, Cormorant Garamond, The Nautigal, and Great Vibes) are packaged and mapped locally so the captured inline font-family names resolve. All bytes and source hashes are recorded in provenance. Reduced motion skips continuous decorations and the opening transitions, shows section content immediately, and still allows the envelope and gift modal to open and close. Source sample names and invitation content are replaced by platform data. Source application runtime, analytics, and demo data are not part of the shipped template.

Catalog artwork: `preview.png` is a 432×768 portrait capture of the post-open source hero rendered from the packaged original markup, exact captured stylesheets, local fonts, and source images. The envelope and platform controls are omitted; the source-bound names use the canonical catalog preview fixture. The image was not redrawn or cropped. `preview.provenance.json` records source and fixture hashes, capture settings, dimensions, and the artwork SHA-256 (`247f9e8cabc4b13f2ac103c290649c6cec1fae36ffaf5b4eb05bd8c954f0e031`). The remote provider portrait found in JSON-LD remains excluded because it contains baked sample names and visible controls. The typed catalog still needs the central owner to set `previewImage` to `/templates/jasmine-white/preview.png`; no shared catalog file was changed in this task.
