# Jasmine White source adaptations

The visual reference is `source/preview-frame.html`, captured byte-for-byte from the archived Chorlove Jasmine White page. The original template module and animation definitions are in `Invitations - this folder will be removed from production/Chorlove/Web invitations/_next/static/chunks/0ziyt946s2g41.js` (SHA-256 `C126D27D5F78DA03D1EF1C4FC5320247D00DC18F697CD3EF0CE2E250AE1335C4`). Both captured stylesheets now load byte-for-byte from the isolated package. The capture and copied asset hashes are recorded in `source-assets.provenance.json`.

`bridge.js` keeps the captured HTML, CSS, images, and font files in the package, and binds invitation data and platform actions to those elements. The source motion chunk is hash-pinned and referenced from the local archive. Fidelity regression checks assert the original opening-petal scale sequence `[1,2,0]`; the adapter now uses the exact 2× midpoint. It replays the source envelope fade (600 ms after a 450 ms delay), envelope lift (800 ms), flower exit (800 ms), petal burst (850 ms), and 1,050 ms overlay lifetime. On opening, the hero enters over 900 ms after a 200 ms delay. The opener also has 12 source-configured falling petals, a heart pulse (2 seconds), and button sheen (3 seconds). Section reveal profiles preserve the source transforms, transition timings, delays, and viewport thresholds. The seven gift flowers use the source lift, rotation, duration, and delay values. The gift artwork opens a source-styled full-screen modal with the captured 250 ms backdrop and card entrance/exit; card details and copy action are supplied by the platform adapter.

The captured CSS references 30 runtime font files; all are packaged and mapped to local URLs. The captured page also declares four named typefaces from the provider `/fonts/` directory; those exact archive files (Qellia, Cormorant Garamond, The Nautigal, and Great Vibes) are packaged and mapped locally so the captured inline font-family names resolve. All bytes and source hashes are recorded in provenance. Reduced motion skips continuous decorations and the opening transitions, shows section content immediately, and still allows the envelope and gift modal to open and close. Source sample names and invitation content are replaced by platform data. Source application runtime, analytics, and demo data are not part of the shipped template.

Catalog artwork: `preview.png` is a 432×768 portrait capture of the unopened source envelope, rendered directly from the packaged original markup with exact captured stylesheets, local fonts, and source floral assets. Only the source-bound couple names use the canonical catalog preview fixture; the source music control and platform language overlay are hidden. The image was not redrawn, reconstructed, or cropped. `preview.provenance.json` records source and fixture hashes, capture settings, dimensions, and artwork SHA-256. The remote provider image remains excluded because it contains baked sample names and visible controls. The typed catalog row points to `/templates/jasmine-white/preview.png`; the template remains unpublished while remaining full fidelity and authenticated public-route release checks are unresolved.

Focused browser QA (2026-10-23): an ephemeral local harness loaded the packaged source page and bridge with a QA-only payload; it did not modify the shared preview fixture or app/catalog code. With `reducedMotion: true`, the root received `jw-reduced-motion`, no source opening petals were created, and activating the opener removed the cover immediately. A single packaged archive gallery photo (`90085094-65d3-45d4-82da-de8d127a859c.webp`) loaded at its native 1440px width, opened in the source-styled lightbox with previous/close/next controls, and the close control removed the dialog. The gift backdrop opened in the same reduced-motion run; the close action was already verified in the live preview during the preceding pass. This QA image was not added to the shared preview fixture or catalog artwork.

No-upload gallery behavior: the packaged bridge filters out gallery entries without image URLs and hides the optional gallery section when preview mode is off and no uploaded image remains (`renderGallery`, `bridge.js`). The one-image lightbox behavior and reduced-motion behavior above were browser-verified. The empty public-gallery case remains covered by source-level checks; it was not freshly exercised through an authenticated public invitation route.

Fidelity follow-up (2026-10-24): full archive search found the exact Jasmine White capture under Chorlove; similarly named Wedvitation pages are different designs. The archived component chunk specifies falling-petal opacity keyframes `[0, 0.85, 0.85, 0]`, which means evenly spaced stops. The adapter had used `0.28`/`0.70`; this is corrected to `1/3`/`2/3`. Multi-keyframe opacity, sway, heart pulse, gift-flower, and opening-petal scale animations now apply their source easing per keyframe segment; the opening petals fade from their in-flight opacity without the extra opacity peak previously present. The focused integrity test asserts the archived opacity/scale sequences and adapted keyframe behavior. The captured HTML, two stylesheets, source motion chunk, referenced images, recovered matching assets, and local font files remain hash-pinned by `source-assets.provenance.json` and `tests/jasmine-white-source.test.ts`.

Live source-to-package comparison (2026-10-24, 390×844): the unopened envelope and first revealed hero were compared in the archived Chorlove capture and local platform preview with original images loading. This exposed an opening defect: `animateSourceHeroEntrance` looked for a header beneath the first section, but the source hero is a page-level header outside the section list. The cover faded out while the hero stayed hidden. The adapter now targets the original page header; the packaged floral frame and names appeared in the same opening state as the source. Reduced-motion opening immediately reveals that hero. All four preview gallery photos loaded from the matching archive assets, and the lightbox's next and close controls worked. The source capture, stylesheet, font, motion-chunk, and image hashes remain checked by `tests/jasmine-white-source.test.ts`; the catalog image hash and typed pointer are recorded above.

The template remains unpublished. The remaining release blocker is completing the documented public-route and invitation-integration checks; this audit did not publish it or claim those checks passed.
