# Green White source integration

The captured `preview-frame.html` is preserved byte-for-byte under `source/`. Eight original design images are copied under `assets/` and recorded with their archive paths, sizes, and SHA-256 hashes. The source's ninth image, `arka2.webp`, is absent from the archive; its observed optimized response is JPEG, stored as `assets/arka2.jpg` with URL, MIME type, size, and hash provenance. The two page-specific lightbox stylesheets remain preserved under `source/styles/`; the runnable page uses the original shared Chorlove stylesheets from the shared package and a small scoped lightbox adapter.

`index.html` keeps the captured 14-section layout and original artwork while omitting the source site's scripts, analytics, source music, and sample invitation values. Its narrow `bridge.js` adapter maps the shared contract's couple names, greeting, message, localized date/calendar/countdown, venue/map, to'yona card and copy action, gallery, dress code and color palette, moderated wishes, RSVP and guest count, contacts, host names, locales, reduced motion, and click-to-play music. The generic Chorlove renderer provides the same adapter to creator preview and public rendering; catalog preview audio uses the shared Emotional Piano.

The isolated bridge restores Green White's source motion from archived page module `12pjntsqxzj70.js` (SHA-256 in `source-assets.provenance.json`). The opening now uses the captured dark-green stage, two top/bottom curtain folds (1.45s and 1.65s delays; 1s cubic-eased reveals), the 2s sparkles/name card, and the 2.15s delayed 0.8s stage fade. The 42 source stars use their original positions, stagger, duration, scale/rotation keyframes, and drift formula. The paired clouds retain their 11s/13s loops. The hero background/cover, lower floral pair, divider, scroll cue, rings, and source-defined scroll reveals now use the original component timings and transform values, including the source viewport threshold and one-time reveal behavior. Reduced motion skips the opening and endless loops and shows all source-initially-hidden content immediately. The captured source and its two source stylesheets remain unchanged; this code maps the compiled component motion declarations onto the preserved server-rendered markup without loading Chorlove site runtime.

The archived source gallery and wishes are sample content and are excluded from the runnable package. User gallery media and approved wishes are supplied dynamically by the app. Only phone and Telegram contacts exist in the shared contract, so the captured Instagram example is omitted. The archived curtain overlay remains dynamic in the invitation renderer; the catalog cover is a static capture of the fully opened first page.

`preview-opening.png` is a 430×573 headless-Chromium capture of the source-rendered first page at portrait size. The ephemeral fixture uses the archived server-rendered HTML, the original compiled CSS, and the original Green White image and font files. It removes Next.js/site scripts, the unrelated suspense shell, and the animated curtain overlay; maps optimized image/font URLs to the exact archived assets; replaces archived sample couple names; shows source-hidden first-page elements at their visible destination; and hides the floating music control. The source captures remain untouched. The image hash, viewport, fixture-only changes, and hashes for the source HTML, stylesheets, and hero image are recorded in `source-assets.provenance.json`. Its catalog path is `/templates/green-white/preview-opening.png`.

Green White remains unpublished pending browser layout/interaction review and full save/publish/public-render/reopen release verification.
