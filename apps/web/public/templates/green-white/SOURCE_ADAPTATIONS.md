# Green White source integration

The original `preview-frame.html` capture is preserved under `source/`; its SHA-256 matches the archive when normalized for Windows checkout line endings. The exact compiled Green White page module is preserved, unchanged, as `source/12pjntsqxzj70.js`. Eight design images match their source hashes. The recovered archive omitted the Green White image directory, so the ninth image, `arka2.webp`, was fetched from its original URL and hash-verified; the runnable page now uses that full-resolution WebP instead of the prior optimized JPEG. The seven font files used by the source stylesheet match the shared package files by SHA-256.

All four original source stylesheets are preserved under `source/styles/`; the original compiled gallery/core chunk is preserved as `source/0jsw~n6ojplnf.js` with its archive hash in provenance. The running page uses the shared Chorlove base styles with font URLs mapped to byte-matching local files, plus the exact YARL lightbox stylesheets. The archived page module uses Yet Another React Lightbox with Zoom, Counter, Slideshow, and Thumbnails plugins; it does not import Fullscreen. The slideshow starts stopped and uses a 1500ms delay. YARL's default carousel uses 16px slide padding, 30% spacing, touch-action none, and a 250ms swipe animation; its pointer controller tracks live horizontal drag, then advances on a 30% distance threshold or a quick flick. The adapter preserves those defaults, displays the adjacent image as the pointer moves, and uses the source 30% gap for slide transitions. It also provides looping arrows and keyboard navigation, manual Play/Pause, thumbnails, counter and zoom, with source-matched 250ms movement and portal fade. The active thumbnail is centered on initial open and selection. The thumbnail rail is 74px tall: 56px image, 2px border, and 16px vertical padding. Reduced motion skips gallery transitions and disables autoplay. Gallery cards are generated only for actual user photos; the whole section hides when none exist. Archived sample gallery photos and sample wishes are not shipped as creator content.

The source opening timeline matches the adapter: top/bottom folds at 1.45s/1.65s for 1s, the 2s title/name sequence, and the 2.15s delayed 0.8s stage fade. The 42 stars retain their source positions, stagger, durations, scale/rotation keyframes, and drift. Clouds retain their 11s/13s loops. Hero entrance, flowers, divider, scroll cue, source viewport threshold and once-only section reveals are mapped from the original module. Dynamic wishes use the source 600ms reveal. Reduced motion is a platform adaptation because the captured source module has no reduced-motion branch; it skips the opening and loops and clears hidden states.

The source conditionally omits gallery when there are no images, To’yona when no card number is present, and contacts when none are configured. The platform keeps dress code behind its approved creator toggle. The source RSVP does have a guest-count stepper that appears after selecting “yes”; the approved platform rule omits the prompt and submits fixed `partySize` values of 1 for “yes” and 0 for “no”. The source obtains translation from its app context and has no visible locale picker; the package adds the localized host-level picker required for invitation locale variants. Instagram is omitted because the shared contact contract supports only phone and Telegram.

`preview-opening.png` is the source-rendered 430×573 portrait cover of the fully opened first page. Its provenance records the archived HTML/CSS and hero-image hashes and fixture-only changes. The animated curtain remains in the invitation renderer. Catalog artwork continues to point to `/templates/green-white/preview-opening.png`.

Green White remains unpublished pending the remaining browser layout/interaction and save/publish/public-render/reopen release verification.
