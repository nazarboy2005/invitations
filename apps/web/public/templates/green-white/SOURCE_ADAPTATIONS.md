# Green White source integration

The captured `preview-frame.html` is preserved byte-for-byte under `source/`. Eight original design images are copied under `assets/` and recorded with their archive paths, sizes, and SHA-256 hashes. The source's ninth image, `arka2.webp`, is absent from the archive; its observed optimized response is JPEG, stored as `assets/arka2.jpg` with URL, MIME type, size, and hash provenance. The two page-specific lightbox stylesheets remain preserved under `source/styles/`; the runnable page uses the original shared Chorlove stylesheets from the shared package and a small scoped lightbox adapter.

`index.html` keeps the captured 14-section layout and original artwork while omitting the source site's scripts, analytics, source music, fixed loading overlay, and sample invitation values. Its narrow `bridge.js` adapter maps the shared contract's couple names, greeting, message, localized date/calendar/countdown, venue/map, to'yona card and copy action, gallery, dress code and color palette, moderated wishes, RSVP and guest count, contacts, host names, locales, reduced motion, and click-to-play music. The generic Chorlove renderer provides the same adapter to creator preview and public rendering; catalog preview audio uses the shared Emotional Piano.

The archived source gallery and wishes are sample content and are excluded from the runnable package. User gallery media and approved wishes are supplied dynamically by the app. Only phone and Telegram contacts exist in the shared contract, so the captured Instagram example is omitted. The captured opening loader is not retained as static content; its scroll-reveal presentation is reimplemented in the isolated adapter and honors reduced motion.

Green White remains unpublished while the canonical portrait fixture artwork, browser layout/interaction review, and full save/publish/public-render/reopen release verification are pending. The in-app browser currently rejects localhost under its URL policy.
