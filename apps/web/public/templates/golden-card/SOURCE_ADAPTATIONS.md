# Golden Card source adaptations

The archive package contains a single `preview-frame.html` file (SHA-256: `75ac0b6d0edd52500a4a24cc15ed001fa6a0230571ce461a33859703180cc888`). It is an HTML snapshot with the server-rendered template subtree, sample invitation values, utility classes, and references to shared Next.js styles. The archived snapshot is preserved byte-for-byte under `source/` (both archive and staged copy: 39,134 bytes; SHA-256 `75ac0b6d0edd52500a4a24cc15ed001fa6a0230571ce461a33859703180cc888`). The captured HTML is accompanied by the archived compiled page chunk `_next/static/chunks/00phb3uac959r.js`, shared CSS bundles, image assets, and font references.

The provider archive search covered Chorlove, E-invitation, Invitate, Invitio, Marxaba, Mytaklif, OnlineTaklifnoma, Taklifiy, Taklifla, Taklifnomachi, Wedivo, Wedvitation, Yoryor, and Yumevite. Golden Card's matching capture and assets were found in Chorlove only; no alternate provider copy was found by template name. All three Chorlove image files referenced by the route chunk were byte-compared with the packaged assets and match.

The package removes the captured Next runtime and sample names, date, and venue from the runnable document. It keeps the captured DOM structure and uses the original compiled Chorlove style bundles already shared by the app. The complete page-specific stylesheet is extracted from route chunk `00phb3uac959r.js` (SHA-256 `f054bd58d6153468c79967a1906e68bb69171b61e76f4e45f914cd1ad627b653`) and placed in `adapter.css`; its only source-level rewrites are local paths for the three packaged images and replacing the remote Google Fonts import with local font files. The archived Great Vibes font is byte-identical to its source copy. The page's Lobster import is served with the exact Google Fonts v32 Latin, Latin Extended, Cyrillic and Cyrillic Extended WOFF2 subsets. The source capture remains untouched.

`bridge.js` maps the shared invitation payload to the captured greeting, title, couple, message, date/time, venue/address, map link, locale controls, and shared Emotional Piano preview track. The original invocation and default invitation sentence remain in the source paragraph structure, localized for the four supported locales; authored message text replaces only the source default sentence. The opening flip retains the source 1.5-second CSS transition. Its entrance, greeting, title, and open-control timings match the compiled component. The sparkle field uses the source's 34 deterministic positions and sizes, source opacity/scale/rotation/y sequences, easing, delays, and 3.4–6.4-second infinite loop; repeated content updates no longer restart it. The invitation reveal follows the source's 700 ms parent delay and 120 ms child stagger, with the source 550 ms child transition; closing now returns the invite content to its hidden variant. The floating music control keeps the source hover scale 1.1 and tap scale .9 feedback, and swaps its volume icon with the playback toggle. The browser/system reduced-motion path skips entrance, flip, and music-control motion while keeping content readable. The captured invitation contains no native RSVP, guest-count, To'yona/gift-disclosure, story, or dress-code section. The product's optional RSVP adapter appears only when RSVP is enabled, offers yes/no with no guest-count question, and sends fixed `partySize` values 1/0. Other source-absent shared sections (including receipt upload) are hidden so they cannot change the captured layout. No captured Chorlove site runtime or external music service is used.

The catalog image is a 335×469 crop from the live shared renderer using the canonical preview fixture. The original navy cover, gold mandala, greeting, fitted invitation title, and opening button are visible; the title clears both side ornaments. The screenshot was captured in the ChatGPT in-app browser at 1280×720 and cropped from the rendered 420×589 opening card to the catalog aspect ratio. The JPEG checksum, dimensions, fixture path, and visual check are recorded in `preview.provenance.json`. The additive registration and publication migrations, four-locale persistence/public-render integration, focused source/catalog checks, typecheck, build, and browser checks passed before release. This fidelity pass additionally verified the visible cover and open state in-browser, confirmed the 1.5-second cover transition, 34 stars and loaded Lobster/Great Vibes fonts, and checked reduced motion.

The live source cover uses the short title “Taklifnoma” on one line. The catalog fixture uses the longer generic title “Bizning unutilmas kunimiz”; the unadapted source-size typography wrapped that text across the ornamental band and collided with the mandala. The bridge now measures authored title text with the active font and scales it to stay on one line within 48% of the cover width, leaving room around the center band’s side ornaments; it recalculates when the card resizes. The reference CSS, short-title size, image assets, and opening animation remain unchanged.
