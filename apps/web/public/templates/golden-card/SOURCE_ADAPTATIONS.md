# Golden Card source adaptations

The archive package contains a single `preview-frame.html` file (SHA-256: `75ac0b6d0edd52500a4a24cc15ed001fa6a0230571ce461a33859703180cc888`). It is an HTML snapshot with the server-rendered template subtree, sample invitation values, utility classes, and references to shared Next.js styles. The archived snapshot is preserved byte-for-byte under `source/` (both archive and staged copy: 39,134 bytes; SHA-256 `75ac0b6d0edd52500a4a24cc15ed001fa6a0230571ce461a33859703180cc888`). The captured HTML is accompanied by the archived compiled page chunk `_next/static/chunks/00phb3uac959r.js`, shared CSS bundles, image assets, and font references.

The package removes the captured Next runtime and sample names, date, and venue from the runnable document. It keeps the captured DOM structure and uses the original compiled Chorlove style bundles already shared by the app. The complete page-specific stylesheet is extracted from route chunk `00phb3uac959r.js` (SHA-256 `f054bd58d6153468c79967a1906e68bb69171b61e76f4e45f914cd1ad627b653`) and placed in `adapter.css`; its only source-level rewrites are local paths for the three packaged images and replacing the remote Google Fonts import with local font files. The archived Great Vibes font is byte-identical to its source copy. The page's Lobster import is served with the exact Google Fonts v32 Latin, Latin Extended, Cyrillic and Cyrillic Extended WOFF2 subsets. The source capture remains untouched.

`bridge.js` maps the shared invitation payload to the captured greeting, title, couple, message, date/time, venue/address, map link, locale controls, and shared Emotional Piano preview track. The opening flip retains the source 1.5-second CSS transition. Its entrance, greeting, title, and open-control timings match the compiled component. The sparkle field uses the source's 34 deterministic positions and sizes, source opacity/scale/rotation/y sequences, easing, delays, and 3.4–6.4-second infinite loop; repeated content updates no longer restart it. The invitation reveal follows the source's 700 ms parent delay and 120 ms child stagger, with the source 550 ms child transition; closing now returns the invite content to its hidden variant. The browser/system reduced-motion path skips entrance and flip animation and keeps all content readable. The captured card keeps its own layout when shared Chorlove sections follow it. Shared Chorlove invitation extras continue to supply app-supported sections such as dress guidance. No captured Chorlove site runtime or external music service is used.

It shows the original navy cover, gold mandala, greeting, invitation title, button, and sparkle field. The saved JPEG checksum, dimensions, fixture path, and browser checks are recorded in `preview.provenance.json`.
