# Chavandoz reference package

This package preserves Marxaba’s captured Chavandoz template source under `apps/web/public/templates/chavandoz`. Its `index.html`, `template.css`, `template.js`, `i18n.js`, metadata, and art are copied from `Marxaba/Sunnat to'yi/templates/chavandoz`. The capture’s `sample-overrides.js` and site-level `sample-invitation.js` are intentionally excluded. Resource paths were adapted to local assets and the established same-origin Marxaba platform bridge; `template.js`’s Three.js URL points to the existing local nikoh runtime. The packaged HTML also declares an empty data favicon to avoid an unrelated site-root 404 and points Open Graph metadata to the actual portrait opening preview. GSAP calls now skip optional selectors when they have no matching nodes, preserving the original tweens wherever their targets exist. The opening carousel, GSAP/ScrollTrigger effects, scroll rider, calendar, RSVP, wishes, gallery, to‘yona, and contact interactions remain implemented by the captured template code.

`fonts.css` and `fonts/` contain the exact Cormorant SC 700 and Nunito Sans 400/600/700/800 font files used by the source, including Cyrillic, extended Cyrillic, Latin, and extended Latin subsets. They are served locally. The source metadata declares `preview.webp`; the original is now preserved byte-for-byte as `source-preview.webp` from `https://www.marxaba.uz/templates/chavandoz/preview.webp` (720×1280, SHA-256 `dae64947a37574f1be8ae08e17ad17809a937fbcb9b6490c054e38dff3bfadd4`). That source file depicts a specific sample invitation crop and differs from the app catalog image. The catalog's `preview.webp` remains the 450×800 authentic browser capture of the packaged source opening, rendered with `apps/web/src/modules/catalog/preview-sample.json` (SHA-256 `3d808aa28f6d5df0685d99f260a7de0319bd7f4b1c1851c0a1a7987571bb73f9`). It shows the clean opening layout and source open action with catalog fixture content. It is a renderer capture, not recreated artwork. `preview.provenance.json` records the source retrieval and both image hashes. The original capture directory was not modified.

## Contract adapter and source fields

The isolated React adapter uses the shared `Invitation` contract and `makeLegacyData`. It maps the first authored person to Chavandoz’s source-only `extras.celebrant` slot, preserving the original data model and leaving source markup intact. Names, host, greeting, invitation message, event label, localized date/time, repeatable program entries, venue text/map coordinates, gallery items, optional music, dress-code palette, contacts, RSVP, gift details, and preview wishes come from the contract or the centralized ephemeral catalog fixture. Locale-specific adapter payloads preserve Uzbek Latin, Uzbek Cyrillic, English, and Russian content. The same captured document is used for preview and public rendering.

Captured metadata declares category `sunnat` and event types `sunnat` and `tugilgan-kun`. The platform event IDs corresponding to these are `sunnat-toyi` and `birthday`; categories remain independent from event compatibility. Registration and publication are deliberately handled outside this isolated package.

The reference contains `extras.celebrant`, `venue.photo`, `toyona.bank`, and `toyona.note`. The shared invitation contract has no independent celebrant field, venue-photo field, bank label, or editable gift note. The adapter aliases the first authored person for the celebrant display. It does not invent a venue image, bank name, or gift note; the shared runtime can show its venue-map fallback when coordinates exist. These fields need no database sample values and remain product-contract gaps for parent integration review.

`contract-adapter.css` hides the captured empty `toyona.bank` and `toyona.note` elements, which have no corresponding fields in the approved invitation contract. The original template stylesheet remains unchanged. Focused fixture tests cover all four locales, the six icon-only preview gallery entries, preview wishes, the six-item program, dress palette, gift/contact content, and a blank invitation with catalog content cleared.

## Verification status

The source package tests check the captured structure, local dependencies/fonts, preview image format, metadata, event types, reduced-motion hooks, unsupported fields, and blank optional gift rows. Browser comparison covered the captured opening and app renderer at desktop and 390×844; the app opening and animated honoree banner fit long names, and the hero has no horizontal overflow. Uzbek Latin, Uzbek Cyrillic, English, and Russian controls work. The opening animation, six-card gallery wraparound, To‘yona disclosure, RSVP guest-count control, and clean console were verified. Focused source/catalog/database tests, typecheck, production build, and the four-locale save/publish/public-render/reopen integration across published templates pass. The captured CSS/JavaScript and shared core honor reduced motion; runtime browser emulation was unavailable. Venue photo and gift bank/note remain unsupported by the approved contract, documented, and left empty rather than fabricated.
