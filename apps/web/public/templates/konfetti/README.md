# Konfetti reference package

This package preserves the captured Konfetti template under `apps/web/public/templates/konfetti`: its `index.html`, `template.css`, `template.js`, `i18n.js`, metadata, and included `art/` files. The original capture remains untouched. The capture's `sample-overrides.js` and site-level sample invitation are excluded. In `index.html`, external font/runtime links are redirected to local files and a local favicon/preview metadata is added. `template.js` keeps the source animation but skips GSAP tweens for the optional celebrant-age/name glyphs and absent gallery cards, which otherwise generated console warnings when those optional data values are empty. These are the only source-level changes.

`fonts.css` packages the Manrope (400–800) and Unbounded (500–900) font faces requested by the original page, with Cyrillic, Cyrillic-ext, Latin-ext, and Latin subsets served locally. Konfetti metadata names `preview.webp`, but no such preview asset exists elsewhere in the local Marxaba capture tree. The package preview was captured by loading the packaged document in headless Chrome at a 450×800 viewport and DPR 1, injecting the catalog fixture fields into `window.name` through the platform bridge, waiting for `document.fonts.ready` and two seconds of the opening animation, then capturing the still-locked candle opener before interaction. The PNG capture was encoded as WebP in Chrome's canvas at quality 0.94. It uses `apps/web/src/modules/catalog/preview-sample.json` data and is not generated or substituted artwork.

## Contract mapping and source-only gaps

The React adapter uses the shared `MarxabaInvitation` renderer and `makeLegacyData`. It supplies the first authored person as the source-only `extras.celebrant` alias. The standard contract fields drive the invitation wording and greeting, event label, localized date/time/timezone, program, venue name/address/map links, gallery, music, dress code, contacts, RSVP, wishes, and gift card number/holder. The same captured renderer is used in preview and public display. Uzbek Latin, Uzbek Cyrillic, English, and Russian are supported; dynamic creator fields come from their active locale, while the captured fixed Uzbek strings use the source's Russian/English dictionary or its Uzbek Cyrillic transliteration behavior.

The captured source also asks for `extras.age`, `venue.photo`, `toyona.bank`, and `toyona.note`. The approved invitation contract does not include a celebrant age, venue image, bank label, or editable gift note. The adapter does not create or infer these values, so the age and venue image remain empty and the optional bank/note slots receive no invented content. The captured `art/venue.webp` and `art/gallery-*.webp` files are retained as source assets but are not injected as visitor or creator media. These fields remain documented contract gaps. The source metadata declares category `tugilgan-kun` and event types `tugilgan-kun` and `yubiley`; shared integration maps these to the distinct typed event IDs `birthday` and `yubiley`. Catalog category and event compatibility remain separate.

## Verification status

The focused package tests check captured sections and controls, local scripts/fonts/assets, source metadata, reduced-motion support, and documented contract gaps. Typed catalog and database rows now register Konfetti as unpublished with birthday and jubilee compatibility; publication remains pending locale, opening, interaction, and responsive browser release checks.
