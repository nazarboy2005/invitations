# Konfetti reference package

This package preserves the captured Konfetti template under `apps/web/public/templates/konfetti`: its `index.html`, `template.css`, `template.js`, `i18n.js`, metadata, and included `art/` files. The original capture remains untouched. The capture's `sample-overrides.js` and site-level sample invitation are excluded. In `index.html`, external font/runtime links are redirected to local files and a local favicon/preview metadata is added. `template.js` keeps the source animation but skips GSAP tweens for the optional celebrant-age/name glyphs and absent gallery cards, which otherwise generated console warnings when those optional data values are empty. These are the only source-level changes.

`fonts.css` packages the Manrope (400–800) and Unbounded (500–900) font faces requested by the original page, with Cyrillic, Cyrillic-ext, Latin-ext, and Latin subsets served locally. Konfetti metadata names `preview.webp`, but no such preview asset exists elsewhere in the local Marxaba capture tree. The package preview is a direct capture of the packaged renderer's still-locked candle opener at 450×800 CSS pixels and DPR 1. It uses the Uzbek Latin birthday fixture name and greeting from `apps/web/src/modules/catalog/preview-sample.json`. The packaged platform bridge's `qaReducedMotion=1` path holds the source-drawn candle flame static. A temporary same-origin capture host hid only the shared runtime's injected `.mh-lang` control; the captured source and shared runtime were not edited. The untouched PNG capture is retained as `preview-capture.png`; `preview.webp` is its WebP encoding. `preview.provenance.json` records both hashes, the fixture, opening state, dimensions, and capture method, and the package test verifies the hashes and portrait dimensions.

## Contract mapping and source-only gaps

The React adapter uses the shared `MarxabaInvitation` renderer and `makeLegacyData`. It supplies the first authored person as the source-only `extras.celebrant` alias. The standard contract fields drive the invitation wording and greeting, event label, localized date/time/timezone, program, venue name/address/map links, gallery, music, dress code, contacts, RSVP, wishes, and gift card number/holder. The same captured renderer is used in preview and public display. Uzbek Latin, Uzbek Cyrillic, English, and Russian are supported; dynamic creator fields come from their active locale, while the captured fixed Uzbek strings use the source's Russian/English dictionary or its Uzbek Cyrillic transliteration behavior.

The captured source also asks for `extras.age`, `venue.photo`, `toyona.bank`, and `toyona.note`. The approved invitation contract does not include a celebrant age, venue image, bank label, or editable gift note. The adapter does not create or infer these values, so the age and venue image remain empty and the optional bank/note slots receive no invented content. In catalog and blank template-selection previews only, the four captured `art/gallery-*.webp` images fill the preview gallery with localized alt text. Creator uploads replace those preview images. The preview fixture and its source-image mapping are ephemeral and never enter drafts or public invitations; public creator-photo galleries remain hidden while empty. The captured `art/venue.webp` remains a source asset and is not injected as visitor or creator media. These fields remain documented contract gaps. The source metadata declares category `tugilgan-kun` and event types `tugilgan-kun` and `yubiley`; shared integration maps these to the distinct typed event IDs `birthday` and `yubiley`. Catalog category and event compatibility remain separate.

## Verification status

The focused package tests check captured sections and controls, local scripts/fonts/assets, source metadata, reduced-motion support, and documented contract gaps. Browser checks compared the captured candle opening with the shared renderer, verified all four locales, the long-name hero, gallery movement, the RSVP guest counter, and clean console logs. At this run the in-app browser viewport override did not take effect, so mobile was not directly rechecked; the captured narrow-screen rules and shared name-fit adapter remain active. Runtime reduced-motion emulation is unavailable; the source script and CSS handle the preference. Konfetti is published at 150,000 UZS through additive migration `0065_publish_konfetti.sql`, under category `birthday` with `birthday` and `yubiley` event compatibility. Age, venue photo, and gift bank/note remain contract gaps and are not fabricated.
