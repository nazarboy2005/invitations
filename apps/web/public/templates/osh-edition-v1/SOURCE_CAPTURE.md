# Osh Edition source and adaptation

- Exact catalog name: Osh; source ID `osh-edition-v1` (E-invitation catalog, not Marxaba Nahorgi Osh).
- Source page: `https://e-invitation.uz/demo/osh-edition-v1/`; captured page remains at its loading screen in the in-app browser.
- Reference package preserves original captured HTML, Vue module (reference only), design/shared CSS, artwork, and font stylesheet/files. These files are not edited or executed.
- The app renderer consumes contract data through `makeLegacyData`: host names/greeting, event copy, date/countdown, venue, map, gallery, and creator-selected music. Catalog uses Emotional Piano.
- Supported event type/category: `osh`. No source audio/video assets or RSVP/wish forms occur in this source design. App RSVP/wishes are therefore not added as unrelated UI.
- Registration is unpublished. Authenticated save/reopen, visual comparison, and release verification are open.
