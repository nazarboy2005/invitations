# Lola source provenance

The captured package lives at `Invitations - this folder will be removed from production/Marxaba/Qiz uzatish/templates/lola`. Its original capture and `capture-manifest.json` remain untouched. The production copy retains the captured HTML composition, styles, motion scripts, and the four art files recorded in the manifest. The only markup adaptation is the three displayed celebrant bindings: the source's `extras.celebrant` slot has no equivalent in the approved shared contract, so it now binds to `bride`; `lola-data.js` maps a single-person invitation from the shared first-person slot into that display slot.

The capture manifest lists `bouquet.webp`, `paper.webp`, `pressed-tulip.webp`, and `sandiq.webp`, but omits `art/sandiq-lid.webp` even though the untouched captured `template.css` uses that exact path for the opening chest lid. The original asset was recovered byte-for-byte from the deployed Lola package at [marxaba.uz/templates/lola/art/sandiq-lid.webp](https://www.marxaba.uz/templates/lola/art/sandiq-lid.webp) on 2026-10-21. Its original 800 × 300 transparent WebP bytes are preserved in the package; SHA-256 `d0745f0cd6b8711be237d3b75812d0b7f67e206de5ca8fbe373c27e166b39622`. The CSS and all captured files remain byte-identical to the local source.

The capture manifest also has no `preview.webp`, although `meta.js` names that catalog asset. The packaged `preview.webp` is a fresh browser render of the captured Lola opening, not a crop of the bouquet artwork. It was rendered at 480 × 900 from the local package after its opening motion settled, using `createTemplatePreviewSample("lola")` from the centralized `apps/web/src/modules/catalog/preview-sample.json` fixture and the `uz-Latn` locale. The visible “Madina”, “Qiz uzatish”, and date come from that ephemeral catalog fixture. Fixture details are never added to template source or saved invitation data. The focused asset test verifies the manifest omissions, local captured-source dependencies, image formats, dimensions, transparency, and the lid's exact SHA-256.

The current deployed package also has an original `preview.webp` at [marxaba.uz/templates/lola/preview.webp](https://www.marxaba.uz/templates/lola/preview.webp); it was inspected to confirm the portrait opening composition. The packaged preview was rendered locally from the actual captured HTML/CSS/JavaScript so the catalog image reflects the centralized preview fixture.
