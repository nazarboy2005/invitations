# Invitate Velvet

Exact capture source: `Invitations - this folder will be removed from production/Invitate/Web invitations/invitate.uz/velvet.html`, resolved from the Invitate capture manifest. The original capture remains untouched. This package includes the captured HTML/CSS/source interaction script, the Velvet opening and background videos, source music, image assets, shared curtain background, the complete font files referenced by the captured Google Fonts stylesheets, and animate.css. Fonts and page assets load from local package paths. The adapter is `apps/web/src/templates/invitate/velvet-adapter.ts` and the iframe bridge is `bridge.js`.

The adapter maps shared invitation people, personalized greeting, message, event date/timezone, venue and map, repeatable program, dress code, gift details, creator photo gallery/Telegram link, RSVP response and optional music. Creator fields replace source sample names, date, venue, program, and RSVP values. The RSVP endpoint is `/api/public/invitations/{id}/rsvp`; song requests are stored as RSVP notes. Empty optional sections are hidden. Built-in controls are localized for Uzbek Latin, Uzbek Cyrillic, English, and Russian. Reduced motion pauses the autoplay videos and disables CSS animation.

Catalog ID `velvet` is registered as wedding-only at 150,000 UZS and remains unpublished. Additive migration `0120_register_velvet_template.sql` is applied to the configured database; the row remains private. Portrait `preview.webp` is a 450×800 capture of the source-video opening overlay before invitation details; capture provenance and hashes are recorded in `preview.provenance.json`.
