# Luxury Gold source adaptations

The untouched source capture is `Invitations - this folder will be removed from production/Chorlove/Web invitations/templates/luxury-gold/preview-frame.html`. A filename and content search across the full invitations archive found this Chorlove page, its two original image assets, and source/capture manifests; no second template package or dedicated catalog cover was found in another provider folder. Exact archive search results are recorded in `source-assets.provenance.json`. The original SHA-256 and byte count, page module reference, source CSS chunk hashes, and packaged asset hashes are also recorded there. The page module is `_next/static/chunks/0io3rqik.2n_m.js` (SHA-256 `0693fc8a88c7a71faa8ff3205ffd3e436b6dfcf410602bbb2f2a72517fe65ecc`). The two custom CSS chunks are packaged without style changes; provenance records the captured and packaged hashes, with line-ending-normalized equality.

`index.html` keeps the 14 captured sections, source utility classes, and the captured opening composition. The source page's app runtime and server-rendered sample invitation values are not used. A visual comparison at 480×720 exposed a missing source font-variable class on the extracted template root: Playfair Display was falling back to sans-serif. The root now carries the original Inter and Playfair Display Next-font variable classes. Their compiled stylesheet and Latin font files are served from the shared source asset package and verified against the Chorlove archive by normalized CSS and byte hashes in `source-assets.provenance.json`.

`bridge.js` adapts the shared invitation contract and platform APIs while restoring the captured page-motion behavior: the two-panel opening and title timeline; once-only section reveals at the source 0.35 visibility threshold; corner ornaments, staggered content, long hero-image zoom, calendar-day spring entrance, scrolling cue, divider and To'yona sheens, gold sparkle canvas, heart pulse, gallery, contact and wish entrances, and map/music/card press effects. Reduced-motion preference skips the opening and looping motion and makes content visible immediately.

The source page-module motion literals are pinned in `tests/luxury-gold-source.test.ts`, and their package mappings are recorded under `sourceMotion.sourceMappings`. This includes the once-only reveal variants and group delays, the 220/15 calendar spring, the 3.6s gift-card sheen plus 2.4s hold, the 2.8s alternating divider sheen, the 3.5s floral pulse, and the 4s countdown-heart pulse. The gift-card keyframe plateau preserves its source timing: 60% of the package's 6s cycle is the 3.6s easing segment and the remaining 40% is the 2.4s hold. Browser inspection in Chrome confirmed a 25-keyframe 400ms calendar spring ending at scale 1, the 6s sheen cycle, and 3.5s/4s ornament and heart loops. Under reduced motion, the bridge marks the root reduced, renders content immediately, and starts no infinite animations. Both modes rendered without page errors.

The captured gallery opens Chorlove's bundled PhotoSwipe viewer with manual slideshow start (1.5 second interval), bottom thumbnails sized 84×56 with 8px gaps and 8px corners, zoom controls, 250 ms swipe transitions, a slide counter, and backdrop close. I opened the original six-photo viewer at 480×720 and confirmed its visible controls and centered active thumbnail strip. The local bridge implements those controls and settings for creator-provided gallery images; an isolated Chrome check passed open, next, zoom, play/pause, thumbnail selection, keyboard navigation, and Escape close. Active thumbnails are centered as in the source. The source component settings and runtime hash are recorded in `source-assets.provenance.json`. The six captured gallery URLs resolve to Orchid Amplop sample media, so they are excluded and never shown as Luxury Gold images.

The original `assets/corner.png` and `assets/bride-groom.jpg` are byte-identical to their captured source assets. Six gallery references point to unrelated Orchid Amplop sample media, so they are explicitly excluded; the gallery is populated only from creator content. Contacts and music reuse the captured card and control elements. The app bridge handles wishes, RSVP, locale changes, and creator-provided content through the shared contract.

The Chorlove archive has no dedicated catalog preview image, so `catalog-opening.png` is a direct browser capture of the untouched archived source page served locally at 480×720 (device scale 1). It was rendered with Chrome 156.0.8078.47 and Playwright 1.64.1; remote requests were blocked. The saved 480×720 PNG was visually inspected and its SHA-256 is `135fa3ae0b552eee35f5754cc60ab2eb39d0015750e7a5ac8637ac293d231df2`. `source-assets.provenance.json` records the source HTML and page-module hashes, browser settings, screenshot hash, and dimensions. ## Full section comparison (2026-10-26)

I compared the archived `preview-frame.html` and packaged `index.html` in Chrome 156 at 480×720, device scale 1. Both render 14 sections. I scrolled each section into the same viewport and recorded its rendered height, scroll height, heading typography, visibility, and active Web Animations. I also opened the page with matching invitation fields; for the package-only gallery fixture, six neutral inline SVG images were used only to exercise source gallery geometry. No fixture image or captured Orchid Amplop sample was added to the package.

| Section | Source / package result |
| --- | --- |
| 0–7: opening, couple, invitation, quote, date, countdown, venue, To'yona | Each is 720px tall in both. Their sampled headings use the same Inter or Playfair Display family, size, weight, and spacing. |
| 8: gallery | 1,318px in both with six items. The source capture's six image URLs belong to Orchid Amplop, so those sample photos stay excluded; production gallery cards use the creator's images. |
| 9: dress code | 720px in both. The user-facing heading differs by locale/content mapping (`Dress-kod` in the captured Uzbek text and `Kiyim uslubi` in the package fixture); layout and source typography match. |
| 10: wishes | Source capture is 896px due to its embedded demo wishes; package is 720px with no demo guest entries. The 176px delta is sample content, not a template layout change. |
| 11: RSVP, 12: contacts, 13: footer | Each is 720px in both when the package has the three matching contact types. |

The source scroller is 10,854px and the package scroller is 10,678px; the entire 176px difference is the source-only demo wishes in section 10. The section tops differ by at most 3px through section 10 from scroll-snap rounding. After section 10, the 176px content-height difference shifts later sections by that same amount. With section 8 and 12 populated, neither section is accidentally hidden. With no creator gallery or contacts, those sections are intentionally hidden by the adapter, consistent with the agreed behavior for empty optional content.

The archived page reports React hydration error #418 in this local browser capture, as well as missing/cross-origin app-runtime requests. That prevents a reliable live, frame-by-frame animation comparison on the archived page. The preserved source module's animation literals and package mappings remain hash-pinned and checked by `tests/luxury-gold-source.test.ts`; the package's calendar spring and sheen/ornament loops were previously inspected in Chrome. This establishes source-code timing correspondence and package runtime behavior, but does not claim that the broken archived browser runtime was observed animating live. A live source replay is the remaining verification gate if the archive can be served without its hydration failure.
