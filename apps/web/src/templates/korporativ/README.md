# Korporativ source package

This is the isolated app copy of the captured Marxaba `Boshqa tadbirlar/templates/korporativ` design. Its `<body>` markup, `template.css`, `template.js`, `i18n.js`, `meta.js`, and four SVG artworks are preserved from the capture. The React adapter at `apps/web/src/templates/korporativ` delegates contract data and supported interactions to the shared Marxaba renderer.

The HTML head is adapted to use local Inter and Space Grotesk font files and the shared, local nikoh runtime. The captured page body and template-owned styles remain unchanged. The source site's shared sample invitation and `sample-overrides.js` are excluded. `fonts.css` supplies local Latin and Latin Extended Space Grotesk faces and the complete Inter subsets already packaged with the platform. The captured script's single local Three.js URL was adjusted to the shared-runtime path used by this app; the loaded Three.js build is the same local version as the captured runtime dependency.

The source metadata declares event IDs `korporativ`, `bitiruv`, and `yubiley`; the typed registry and database seed preserve that compatibility. It is assigned to the existing general-purpose `other` catalog category because categories are independent of event types and an administrator can reassign it. Migration `0074_publish_korporativ.sql` is applied; PostgreSQL and the public catalog verify it published at 150,000 UZS.

The shared adapter maps the contract's first person to the source-only `extras.celebrant` slot, along with localized event copy, date, venue name/address/map links, program, gallery, dress code, contacts, To‘yona, RSVP, wishes, and music. Korporativ uses a single honoree field; existing extra names in an older draft remain preserved in storage, while the source renderer shows the first person. The source also contains `program[].speaker`, `extras.parking`, and `venue.photo` slots. The contract has no speaker, parking, or venue-photo field. The app-owned `contract-adapter.css` hides these source-only empty areas without substituting unrelated media. For gallery cards without images, it hides the captured archive label while keeping the shared renderer's decorative icon placeholder; cards with real images preserve the source label. Catalog and initial-selection previews use the four captured SVGs as ephemeral gallery images only when the creator has not uploaded photos. This preview mapping never enters saved invitation data, and public empty galleries stay hidden. The captured maps can use the typed venue map URL when provided.

`meta.js` points to `preview.webp`, which is absent from the local reference capture. The exact 720×1280 asset at that official metadata URL is now packaged unchanged; its SHA-256 and provenance are recorded in `preview.provenance.json`. The localized corporate fixture matches the artwork's “Yil yakuni kechasi” label, Marxaba Tech honoree, and 14 November 2026, 18:30 date/time. The local source capture remains untouched.

The centralized preview fixture contains localized corporate sample content for all four locales, including one company honoree, agenda, and non-wedding attire guidance. Focused source/contract tests compare the packaged body, CSS, JavaScript, localization, metadata, and artwork against the capture and validate local paths, fonts, motion support, preview dimensions, unsupported typed-data fields, and the shared Emotional Piano catalog audio. On 2026-10-22, focused Korporativ tests passed 9/9 and the production build passed. A disposable PostgreSQL/app integration passed the four-locale save, publish, public-render (HTTP 200), and reopen path; QA users, invitations, sessions, database, environment file, and media were cleaned afterward. The browser tool rejected access under its URL-policy gate; desktop/mobile rendering, locale switching, browser reduced-motion, interactions, and console checks remain unverified. Korporativ is published through the configured catalog; these prior browser QA gaps did not change that verified database state.
