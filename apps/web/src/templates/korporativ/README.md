# Korporativ source package

This is the isolated app copy of the captured Marxaba `Boshqa tadbirlar/templates/korporativ` design. Its `<body>` markup, `template.css`, `template.js`, `i18n.js`, `meta.js`, and four SVG artworks are preserved from the capture. The React adapter at `apps/web/src/templates/korporativ` delegates contract data and supported interactions to the shared Marxaba renderer.

The HTML head is adapted to use local Inter and Space Grotesk font files and the shared, local nikoh runtime. The captured page body and template-owned styles remain unchanged. The source site's shared sample invitation and `sample-overrides.js` are excluded. `fonts.css` supplies local Latin and Latin Extended Space Grotesk faces and the complete Inter subsets already packaged with the platform. The captured script's single local Three.js URL was adjusted to the shared-runtime path used by this app; the loaded Three.js build is the same local version as the captured runtime dependency.

The source metadata declares event IDs `korporativ`, `bitiruv`, and `yubiley`; the typed registry and database seed preserve that compatibility. It is assigned to the existing general-purpose `other` catalog category because categories are independent of event types and an administrator can reassign it. The template is registered but remains unpublished and unavailable for selection.

The shared adapter maps the contract's first person to the source-only `extras.celebrant` slot, along with localized event copy, date, venue name/address/map links, program, gallery, dress code, contacts, To‘yona, RSVP, wishes, and music. Korporativ uses a single honoree field; existing extra names in an older draft remain preserved in storage, while the source renderer shows the first person. The source also contains `program[].speaker`, `extras.parking`, and `venue.photo` slots. The contract has no speaker, parking, or venue-photo field. The app-owned `contract-adapter.css` hides these source-only empty areas without substituting unrelated media. The captured maps can use the typed venue map URL when provided.

`meta.js` points to `preview.webp`, but the reference directory contains no preview file. The app copy includes an authentic 720×1280 portrait capture of the opening screen rendered from the centralized catalog fixture; the source capture remains untouched. No creator sample data is part of this package or any saved invitation.

The centralized preview fixture contains localized corporate sample content for all four locales, including one company honoree, agenda, and non-wedding attire guidance. Focused source/contract tests compare the packaged body, CSS, JavaScript, localization, metadata, and artwork against the capture and validate local paths, fonts, motion support, preview art, and unsupported typed-data fields. The package remains unpublished pending desktop/mobile browser, locale, reduced-motion, console, and save/reopen verification.
