## Source and field mapping

Exact captured CSS bytes, marigold artwork and Caprasimo/Figtree fonts are
checksummed in dependencies.json. The native opener, ten falling petals,
reveal observer and closed-wishes panel builder run directly. Original captures
stay untouched. Provider analytics, demo records and guestbook runtime are excluded.

| Source field | Shared binding |
| --- | --- |
| Names, monogram, greeting and invitation | localized people, greeting, hosts, message |
| Date/countdown/program | startsAt/timezone, stable program IDs |
| Venue and map action | shared Google URL, coordinates or authored address search |
| Bride/groom family, accommodation, footer | localized validated templateData fields |
| Hashtag | validated templateData hashtag |
| Wishes | canonical preview-only feed or real approved/pending API |
| Music | creator URL; gesture-gated canonical catalog track |

Family/accommodation/footer/hashtag omissions are restored with real editor,
validation and save/reopen/switch support. Generic wedding details in the shared
preview JSON feed both this and Gulbog; common content remains reusable across
all designs. No creator save or public invitation receives sample data.
A stable renderer payload memo prevents preview chrome rerenders from resetting
language or form input. Native language switching refreshes canonical wishes.
Source phone RSVP prose and nontransactional gift blessing remain intact;
no attendance-count input or payment form is added.
