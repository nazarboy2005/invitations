# Yubiley Sahifasi — Taklifla Bookie Navy

Full navy corporate anniversary source, shared real renderer in catalog/studio/public.
Corporate event compatibility is separate from catalog category `other`.
Registration migration 0175; release migration 0176 after complete verification.

## Source and adaptations

`source/provenance.json` records the immutable full capture, exact source CSS,
font files and city photograph. Inline architectural/geometric SVGs and original
CSS/reveal engine are retained. Only template source is served; provider runtime,
localStorage RSVP simulation, captured company/personal samples and analytics
are excluded. Original reference captures are untouched.

The private package had removed the central anniversary years, closing years,
statistics and milestone years. These source fields now persist in validated
`templateData["taklifla-yubiley-sahifasi"]`, with editor controls for years,
localized founder role, dates keyed by stable story ID, and ordered statistics
with stable IDs/localized labels. Creator names/company, greetings, signature,
message, stories, program and venue come from the shared contract. Founder
signature uses hosts; role uses the source-specific setting, company reuses people.
No founder/company sample data enters a draft. Empty optionals hide cleanly.

The source map illustration is a keyboard-accessible link to the shared Google
venue URL, coordinates or authored address. Selected/manual URLs are preferred;
no browser map key is embedded. RSVP uses the real shared API: attendance is 1/0,
organisation is included in note, success waits for API acknowledgement, errors
retain inputs and deadline/guest identity are retained. No guest-count input.
There is no source wish form, gallery or gift interface to fabricate.

All four locales and reduced motion are supported. Source plus signs, numeric
styles, reveal timing and decorative frame remain. Music uses creator audio;
canonical catalog track is gesture gated and pause survives language changes.
The canonical corporate event profile owns illustrative statistics/milestones;
preview-only data never persists. No template-specific semantic sample file.

## Verification

Package tests verify capture/CSS/fonts/photo hashes, four locales, maps,
source-specific values, empty data, mutation isolation and typed validation.
`tests/taklifla-yubiley-sahifasi.browser.cjs` compares source/app at 320/390/1280,
checks scroll motion, seven stable repeated statistics/milestones, long content,
preview no-send, error retention, reduced motion and empty optionals.
`tests/taklifla-yubiley-sahifasi.integration.ts` verifies disposable real
save/reopen, source details, compatible switching, publication, studio/public,
four personalized locales, Google venue edits and real one-person RSVP.
Actual audio, source comparisons, catalog and personalized covers are recorded
under `docs/templates/taklifla-audit`. No external application deployment or payments.
