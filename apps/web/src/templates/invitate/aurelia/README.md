# Aurelia source package

Aurelia is adapted from the existing ignored Invitate capture. The reference
capture remains untouched. The production package preserves the captured HTML,
CSS, JavaScript, Trajan fonts, SVG ornament artwork, and hero video. It omits
reference tracking, SEO/runtime code, and sample invitation names or photos.

The isolated page adapter maps localized people, greeting, invitation message,
date/countdown, venue/address/map, program, two optional gallery photos,
contacts, RSVP, and moderated wishes from the shared invitation contract. The
captured design has no story, music, or dress-code section. Its captured
celebration image and Yakkasaroy venue photo remain as replaceable visual defaults. The first
creator gallery photo replaces the celebration image, and the second replaces
the restaurant image; when either upload is absent, its captured default stays
visible. These defaults are template assets and are never written into the
invitation content. A design-matched optional To‘yona section uses the shared card number and cardholder fields and provides a localized copy action. The shared preview fixture supplies catalog and
initial-selection examples only; those values are never saved.

The four supported locales are Uzbek Latin, Uzbek Cyrillic, English, and
Russian. The locale control follows the fixed header pattern used by Anor, and
the hero video pauses for reduced-motion preferences. The same packaged page is
used in creator preview and public invitation display.
