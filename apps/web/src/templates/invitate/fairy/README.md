# Fairy source package

Fairy is adapted from the local Invitate capture at `Web invitations/invitate.uz/fairy.html` and its `assets/css/fairy.css`, `assets/js/fairy.js`, `assets/images/fairy/*`, `assets/fonts/*`, and `assets/audio/mus.mp3`. The capture folder remains untouched. The isolated page keeps the captured HTML hierarchy, styles, art, music control, calendar, countdown, scroll reveals, and decorative motion. Reference analytics, social metadata, fixed sample names/date/program/venue/dress copy, and the source's pretend RSVP success handler are excluded.

The platform adapter binds title/event label, people, personalized greeting, invitation copy, event date/time and calendar, repeatable program times/titles, venue/address/map, dress text and color palette, optional creator music, active locale, RSVP, and moderated wishes. The design's decorative venue photo stays a template asset. The captured page has no editable gallery, family/host block, contact-data form, or To‘yona/card-entry section; its footer contact icons bind the shared phone and Telegram values where configured. Do not add gift UI to Fairy. RSVP and wishes use the public invitation API and show errors when requests fail.

The exact captured Google Fonts stylesheet is retained as local subset CSS. Its 11 captured WOFF2 files cover the recorded Latin/Cyrillic faces; locally stored TTF faces under `assets/fonts/google` provide offline fallback for subsets absent from the capture. No runtime font request goes to the source website. The renderer consumes the shared invitation contract in preview and public display and supports Uzbek Latin, Uzbek Cyrillic, English, and Russian. Reduced-motion CSS suppresses decorative movement and transitions. The captured 52px name size is retained for ordinary names; the adapter measures and shrinks unusually long names only when needed to fit the opening frame.

The unpublished 480×850 catalog image is a portrait capture of the source-authentic opening rendered with the shared `preview-sample.json` fixture. Fixture data was injected only for that capture and is not present in the template package or public invitation data. `preview.provenance.json` records hashes for the untouched captured source, adapted page/scripts/styles, and captured font subset files separately.

The source page and isolated package were opened in headless Chrome at a matched 390×844 viewport with local source assets and the same Uzbek names and concise date. Normal and `prefers-reduced-motion: reduce` states were inspected. The frame, opening artwork, typography, names, and date align when they use the same fixture values. The package intentionally adds the platform language selector, localized event label, and data-bound names/date, and hides the music control when no creator track is configured. Public normal-motion rendering retains the source's one-second preloader/reveal; the catalog preview opens immediately, and reduced motion skips the preloader. RSVP preview shows a failure state without sending; public RSVP and wishes remain API-backed. Exact source/package screenshots were captured for comparison during this QA pass and are not implementation assets.
