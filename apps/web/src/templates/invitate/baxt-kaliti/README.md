# Evelina source package

Evelina is the first source-backed Invitate design on the isolated
`codex/invitate-templates` branch. The original capture is already present in
the ignored reference folder. The reference folder itself remains untouched.
The adapted production page and its contract adapter are packaged separately;
no sample invitation data or reference-site application code is copied.

The public package keeps Evelina's captured HTML structure, styles, font faces,
opening art, video transitions, crystal motion, countdown arrangement, RSVP
composition, and typography. App-scoped adaptations localize controls, map the
shared invitation contract into the captured page, use local font files, honor
reduced motion, and connect RSVP/wish forms to the public APIs. Tracking code,
remote runtime requests, reference-site contacts, the sample invitation,
the `send.php` endpoint, and unrelated sample photography are excluded.

Fields mapped: people and personalized greeting; invitation message and event
label; timezone-aware date, countdown, and program entries; venue, address, and
map directions; optional portrait gallery photo, dress code, contacts, music,
RSVP, and moderated wishes. The captured design has one portrait photo slot and
no full gallery or story section. Its oval photo frame cycles through
creator gallery images when more than one is supplied. An optional, design-matched To‘yona card flips to reveal the shared card number and cardholder, with a localized copy action. The shared preview's
empty gallery entries and sample invitation content remain ephemeral.

The typed catalog and additive migrations register and publish wedding
compatibility and the wedding category at 150,000 UZS after the focused source,
renderer, typecheck, production build, and authenticated save/publish/public
render/reopen checks pass.
