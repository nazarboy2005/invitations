# Artwork source

The built-in image generator returned HTTP 403 during this task. Per the imagegen
workflow, no CLI/API fallback was used. The final artwork is authored as the
scalable, self-contained `assets/background.svg`: emerald cotton-paper texture,
geometric girih border, understated corner ornaments and an ivory QR quiet zone.
No variable text or third-party asset is baked into the background.
