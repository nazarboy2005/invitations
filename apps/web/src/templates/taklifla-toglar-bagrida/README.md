## Source and adapters

Immutable capture and exact template/control styles, eleven watercolor artwork
files and nine local fonts are recorded in source-provenance.json. The original
three mountain idle layers, scroll parallax and reveal observer run directly.
A narrow guard makes parallax respect the preview reduced-motion flag; native
reduced-motion CSS remains. Provider app scripts, analytics, query customizer,
localStorage demo state and guestbook client are excluded.

| Source field/action | Contract/platform binding |
| --- | --- |
| Hero, names, monogram, greeting, wording, footer | localized people, greeting/personalGreeting, message, hosts |
| Two editable scene titles/text | first two shared story chapters, stable IDs |
| Scene time overrides | validated templateData ceremonyTime / celebrationTime; blank uses startsAt |
| Date, mandala countdown | startsAt and timezone |
| Timeline | all shared program items and localized text, stable IDs |
| Venue/address and source action | shared venue Google URL/coordinates/address search |
| Wish form/wall | real approved/pending API and resolved guest token |
| Language/music controls | enabled locales, real optional audio; catalog gesture only |

The private source package omitted independent scene times, canonical wishes,
address search and production registration. These are restored. Editor time
fields persist and survive compatible switching; shared story editing changes
the source scene cards. Source default scene copy stays until authored; an
explicitly cleared scene title hides that card, as in the original. No extra
attendance-count or payment UI is added. Catalog/initial-selection content,
Google venue, wishes and scene time examples derive only from the canonical
shared fixture. Public invitations never receive samples.
